> 所有色值、间距、圆角、动效曲线与状态机均以本文件为准；实现不得偏离，如需偏离须先改本文件。

> **修订说明（2026-10）**：第 0 节是当前实现的权威基线，第 2、3、4、7、12 节中与它冲突的历史原型数值以第 0 节为准。历史章节仍保留几何推导与交互规范，色值与字号表正在逐步回写。

### 0.3 排版阶梯

| 角色 | 字号 / 行高 | 用途 |

| 三级标题 | 15 / 24 | 正文 h3、小区块标题 |

| 界面行 | 14 / 20 | 列表主行、配置标签、导航 |
| 次级 | 13 / 20 | 控件文字、表体、按钮 |
| 说明 | 12 / 20 | 说明段、卡片描述 |
| 紧凑说明 | 12 / 16 | 单行元信息、表头 |
| 代码 | 12 / 20 | 代码块、预览、行号 |
| 角标 | 11 / 16 | 快捷键角标 `Kbd`、分组小标题 |
| 微标签 | 10 / 16 | 仅时间戳、计数、坐标轴刻度 |

- 14px 是界面主行，13px 是控件与表格；两者不得在同一行交替。
- 10px 不得承载中文说明、字段标签或表头；表头用 11-12px。
- 组件里不得再用裸 `text-base` / `text-lg` / `text-xl` / `text-2xl` 做标题。
- 字体族只有两支，且都取系统栈：界面与标题走 `--font-sans`（`-apple-system` 打头的系统无衬线），代码与等宽数据走 `--font-mono`（显式带 `'Microsoft YaHei'` 兜底，不以裸 `monospace` 收尾）。**不打包任何 webfont**。
- 标题字重：h1 至 h3 取 700，h4 取 600；正文 `strong` 取 600，不与标题同重。
- 中英混排交给排版引擎的 `text-autospace: normal`；代码与等宽片段声明 `no-autospace`，保留源文本列对齐。

### 0.5 页面骨架

- 沉浸式一体窗口：Windows / Linux 采用无系统边框窗口配右上角原生感 `WindowControls`（最小化、最大化/还原、关闭），macOS 采用 `Overlay` 标题栏保留左上交通灯；所有 40px 顶栏支持拖拽移动窗口。
- 对话页：40px 指标条 + 定宽对话流 + 底部双层倒角输入坞（浮在画布上，聚焦保持立体投影不塌陷）。
- 管理页（工作区、自动化、目标看板、记忆）：`PageShell` 40px 顶栏（左标题 14/20 500，右动作 28px）+ `max-w-page`（88%）+ 唯一滚动层。目标看板的分栏变体见 §11.1。
- 设置：统一面板尺寸、分区标题（16/24 500 + 12/16 说明）、内容区唯一滚动、底部固定状态行。
- 侧栏：280px 展开 / 56px 图标轨；< 1024px 自动收轨，用户手动偏好优先；选中项采用微浮起卡片态（`bg-surface shadow-lift`）。
- 右侧停靠栏：默认收起，展开 45%；tab 条 40px；三个控件 28px；终端主题随当前工作台主题动态切换（暖石与冷杉为浅色终端，黑曜石为深色终端）。

### 0.6 动效

- `--ease-standard: cubic-bezier(0.4, 0, 0.2, 1)`。
- 物理弹簧三档（三主题一致）：`--ease-spring-tactile: cubic-bezier(0.34, 1.56, 0.64, 1)`、`--ease-spring-smooth: cubic-bezier(0.16, 1, 0.3, 1)`、`--ease-spring-exit: cubic-bezier(0.4, 0, 1, 1)`。
- 常用时长：100ms（hover）、110ms（弹出层退场）、140ms（模态入场）、150ms（开关与回执）、250ms（抽屉）。
- 模态入场只动 `opacity` 与 `transform`，不做宽度或高度动画；退场走 `data-state="closed"` 的 110ms 缩放淡出，走完才卸载，卸载前保持上一份内容因此不会塌陷。嵌套弹窗不再叠第二层遮罩，遮罩的模糊半径恒为 2px。
- 按键动效为非对称：松开 200ms 弹簧回位，按下 50ms 下沉到底；通用按钮不常驻 `will-change`。
- 主题切换是双 `requestAnimationFrame` 瞬切：首帧挂 `.disable-transitions`，第二帧后摘掉，单帧完成、无颜色插值残影。
- 其余动效铁律同第 5.3 节。

### 0.7 主题系统

三套主题共用同一套几何、字号、间距与组件形态，只换调色板、光学高度与语法色板。

| 主题 | 标识 | 情绪 | 画布 | 主操作 |
|---|---|---|---|---|
| 纸白 | 不挂属性，默认（`paper`） | 清透、纯净、亮白 | `#FAFAFC` | `#18181B` |
| 冷杉 | `data-theme="forest"` | 松雾、冷矿、静谧 | `#F2F5F4` | `#144534` |
| 黑曜石 | `data-theme="obsidian"` | 深邃、钨钢、精密 | `#11141B` | `#2F5FD0` |

**令牌分层。**

- `@theme` 与 `:root` 承载纸白（`paper`）的全部取值，组件类名照常由框架生成。
- 冷杉与黑曜石只声明与纸白不同的令牌，分别写在 `html[data-theme='forest']` 与 `html[data-theme='obsidian']` 块里，其余全部继承。
- 选择器必须是 `html[data-theme='<name>']`（特异性 0,1,1），不要用 `[data-theme]`，否则与 `:root` 同级，只能靠源码顺序决胜。
- 主题块只允许出现在 `tokens.css`，组件里不得出现按主题硬编码的颜色分支。

**主题可以改**：颜色、描边、投影、天光、图表色板。
**主题不可以改**：几何、字号、间距、组件形态、动效曲线、图标体系。

**切换与首帧。**

- 属性挂在 `document.documentElement` 上。纸白是清空属性而不是写 `"paper"`，任何遗漏路径都自然回落默认主题。
- 首帧由 `index.html` 的同步内联脚本读 `localStorage` 镜像，避免先画默认主题再跳色。
- 磁盘是事实源，`localStorage` 只是缓存；启动拿到后端值后校正一次。
**设置入口。** 主题不用分段控件，用两张带缩略预览的卡：两套主题的差别主要在底色与留白，光看名字选不出来。缩略图用固定的 `--color-swatch-*` 色板（描述的是另一套主题，不随当前主题变化），选中态给 `border-primary` 与实心勾。

**门禁。**

对比度按主题逐套校验：每个主题都必须声明画布与卡片两档底色，每个承载文字的令牌都要在两档底色上过正文 AA。新增主题时，`tools/verify-ui-contract.ps1` 会自动把它纳入校验，不需要改脚本。

### 0.8 系统材质与窗口光学

窗口材质是**可选增强**，不是界面的前提：材质不可用时界面必须与今天完全一致，不出现半透、发灰或四角毛刺。

| 平台 | 材质 | 触发 | 降级 |
|---|---|---|---|
| Windows 11（Build 22000+） | DWM Mica | 启动时 `window_vibrancy::apply_mica` 成功，且每次主题切换同步 `set_theme` | 失败（含 Windows 10）时绝不回退到有重绘拖影的 Acrylic，直接注入 `data-material-fallback="solid"` 走 100% 实色托盘 |
| macOS（12.0+） | `NSVisualEffectMaterial::Sidebar` | 启动即应用 | 低版本保持标准毛玻璃，材质不可用时同样退回实色 |
| Linux | 无 | 不启用透明合成 | 恒定 100% 实色托盘，窗口仍是无边框加复合器阴影 |

- **状态机作用域下沉**：`data-window-focused` 与 `data-window-maximized` 只挂在侧栏容器 `.app-shell-sidebar` 上，不挂 `:root`。长会话里上千个节点不该因为一次窗口失焦而全树重算样式。
- **最大化事件来自宿主**：Rust 侧只在最大化状态真的翻转时推一次 `axon://window-maximized-changed`；前端不做 resize 轮询，也不每个尺寸变化都问一次 `isMaximized()`。
- **实色回退是性能选择**：失焦与最大化时托盘退回 `--color-sidebar`，停止 DWM 混合采样；最大化时底层壁纸本来就被完全遮住，留着半透只多付采样开销。
- **窗口几何静默记忆**：只恢复尺寸、位置、最大化与全屏四项，**不恢复可见性**。窗口初始不可见，前端首帧就绪信号（`desktopNotifyReady`）到达或 350ms 兜底超时后才显示，因此没有白底闪烁，也没有窗口瞬移。
- **零 GPU 噪点**：微晶纹理是静态 Base64 PNG 平铺（`.noise-underlay`），不用 `<feTurbulence>` 一类实时滤镜；实时滤镜会让拖拽与滚动持续占用像素着色器。

### 1.1 核心区域构成与布局几何

1. **左侧导航侧栏 (Sidebar)**
   - **展开与折叠列宽**：默认宽度 **280px**（用户可在 264px 至 420px 间自由拖拽；拖至小于 140px 时自动收缩为图标轨）；折叠后为固定 **56px** 的紧凑图标轨（`SidebarRail`：含展开按钮、新建会话、自动化任务、工作区与底部设置图标）。
   - **顶部品牌行 (h-12 / 48px)**：包含 Axon 标志徽标、应用标题与侧栏收起按钮（快捷键 `Ctrl+B`）。
   - **主快捷入口**：`[+] 新建会话` 按钮（悬停显示 `Ctrl + Alt + N`）以及 `🕒 自动化任务` 独立入口。
   - **工作区与会话树**：支持多工作区组织，带搜索、视图过滤（按更新/创建时间排序、归档过滤）与新建工作区入口；工作区项支持折叠/展开并标记当前活动项；会话项展示标题、相对时间戳（如“4分钟”）、运行状态圆点 `StateDot`、置顶图钉与右键/悬浮操作菜单。
   - **底部固定设置入口**：固定吸附于侧栏底部，点击唤出全局设置弹窗（快捷键 `Ctrl+,`）。

2. **主区域顶部运行态指标条 (ConversationHeader / HeaderBar)**
   - **高度与发丝线**：固定高度 **36px**（`h-9`），带下发丝线边框 `hairline-b` 与纯净画布底色 `bg-canvas`。
   - **紧凑型指标流**：左侧与中段展示运行态指标段（以 `·` 间隔），可自由双击选中与复制：
     1. 待答复标记：`❓ 待答复`（仅在模型触发 `ask_user_question` 挂起时高亮呈现）。
     2. 运行状态：一枚 22px 的活动点（`--color-text-link` 12% 底色圆 + 同色 `AgentIcon`，`aria-label="正在运行"`），只在工作态出现，结束时整段消失。指标条不写品牌名：模型与身份已由侧栏与输入坞承担，这一格只回答「现在在不在干活」。
     3. 工作区路径：`📁 <workspace-root>`（当前工作区真实物理路径）。
     4. 目标通道：会话 destination。
     5. 上下文容量胶囊：环形进度圈 `RingIcon` + 如 `554K/1M`，悬停/点击呼出 `ContextUsagePopover` 弹出卡片，展示输入、输出及缓存明细。
     6. 缓存命中率：如 `命中率 97.89%`，直接显示；仅在有完整输入 token 时出现。
     7. 首字延迟：TTFT（如 `240ms`）。
     8. 生成速率：生成吞吐（如 `45 tok/s`）。
     9. 计划完成度：如 `2/4 步`。
     10. MCP 台数：`MCP 3`；有服务器没加载起来时写 `MCP 2 · 1 异常` 并整段取危险色（悬停说明总台数与原因），一台都没有且没有错误时不占位。与 LSP、计划同属辅助簇，窗口不足时随辅助簇一起退场。
     11. 技能条数：`技能 12`，紧跟 MCP，与设置 › 技能页的清单同一份来源（技能目录下的一级技能目录）；悬停说明「共 12 项已安装技能」。清单未读到或零条时不占位，正常态取默认墨水色，与 LSP、MCP、计划同属辅助簇。
   - **右侧 Trailing 操作区**：
     - 运行时动作胶囊 (`RuntimeActions`)：显示后台作业与子代理运行状态（如 `后台任务 1`），点击展开管理下拉层。
     - 资源面板开关 (`IconButton`)：点击平滑展开右侧资源面板。

3. **中部主对话流 (ConversationStream)**
   - **定宽居中**：正文容器采用 `max-w-chat` 居中约束，宽屏下默认上限 **840px**，两侧保留呼吸留白；支持通过 `ConversationWidthControls` 控件自由微调（680px ~ 1100px）或双击复位。
   - **排版范式**：
     - 用户消息：右上对齐不对称圆角气泡（浅灰色底 `container-high`），悬停显示快捷操作。
     - 助手回答：通栏白板排版，无外层气泡包边，左对齐；支持代码语法高亮块（带行号与复制按钮）、Markdown 表格、数学公式及图文混合。
     - 工具调用与执行：轻量折叠卡片（状态圆点、工具全名、调用参数摘要、执行耗时与结果展开折叠）。
   - **首屏空态 (Hero)**：居中呈现 Axon Logo、品牌标语“知你所想，办你所托”与使命阐释，直连下方输入坞即可立即开启任务。

4. **底部复合输入坞区 (PlanDock + InputDock)**
   - **固定计划坞 (PlanDock)**：钉在输入坞正上方，与输入坞等宽对齐，显示会话当前计划进展（如 `📋 计划 1 进行中 · 3 待处理`），可点击折叠/展开，不随聊天记录滚走。
   - **复合输入卡片 (InputDock)**：
     - 状态提示行：显示“正在处理...”状态扫光条（`working-sweep`）、耗时及 `按 ESC 中断` 提示。
     - 大圆角输入卡片（`rounded-[20px] bg-surface hairline shadow-panel`）：
       - 顶部附件预览栏：支持图片缩略图、文件胶囊与移除按钮。
       - 多行自适应输入框（`ComposerTextArea`，最大向上伸展 6 行，支持 `@` 文件/目录引用提示菜单、`/` 技能/斜杠指令补全菜单）。
       - 底部操作栏：左侧添加附件按钮（`+` 图标），中间弹性留白，右侧模型与思考等级选择器（`ComposerPicker`，例如 `gemini-3.8-flash High`）+ 发送/停止胶囊按钮。

5. **右侧扩展抽屉面板 (SidebarRight - 按需展开，非常驻三栏)**
   - **默认状态**：完全折叠收起（占位宽度归零，贴右边缘滑出视野，不侵占正文阅读空间）。
   - **展开形态与列几何**：
     - 首次展开取帧宽的 **45%**。
     - 拖拽调整区间：下限 **300px**，上限 `min(帧宽 × 0.7, 帧宽 − 400px)`。
     - 中间正文列安全保护：任何时候不低于 **400px**。
     - 自动全屏：帧宽低于 **768px** 时，展开的面板自动全屏（`fullscreen` 模式）。
   - **承载内容**：Tab 集合驱动的扩展功能区，包括改动文件树（`ChangedFiles`）、代码文件预览（带语法高亮与行号）、Diff 对比与扩展视图。

### 1.2 断点与容器约束

| 断点 | 视口宽度 | 导航侧栏 | 对话流宽度 | 输入坞与计划坞 | 右侧扩展面板 |
|---|---|---|---|---|---|
| 紧凑 | < 600px | 折叠隐藏，点击汉堡按钮唤出覆盖式抽屉 | 100% 满宽，两侧内边距 16px | 贴底固定，左右边距 12px~16px | 自动全屏覆盖 (Fullscreen) |
| 中等 | 600 至 1024px | 折叠为图标轨 **56px** | 720px 水平居中 | 居中，最大 720px，与对话列等宽对齐 | 支持 Push 挤压或覆盖 |
| 宽屏 | > 1024px | 展开 **280px** 常驻占位 (264~420px 可调) | **最大 840px 严格居中** (可微调) | 最大 840px 居中对齐，距底边 20px | 默认收起；展开占帧宽 45% (可拖拽 300px+) |

### 1.3 阅读舒适律（硬性）

对话正文**默认最大宽度不得超过 840px**。单行字符数维持在 45 至 75 的黄金视线移动区间，无论物理屏幕多宽，主工作流两侧均填充画布底色。当右侧资源面板展开时，正文列仍受 `CENTER_MIN (400px)` 严格保护，确保内容不被压缩变形。

## 2. 色彩与设计令牌

> **数值以 §0.1 与 §0.2 为准**。本节保留色彩语义、对比度推导与使用约束；表中与 §0 冲突的历史原型值（暖骨白、蓝强调、container 阶）不再实现。

现代中性黑白极简工业风格（对标 DSH 与 Codex 极客美学），纯净中性纸白为底，深邃高对比近黑碳墨为文字与主操作，细腻发丝线为结构分隔，无杂色冷蓝，无霓虹与极光渐变，微型 3px 极细低感知滚动条。

### 2.4 语义色

| 角色 | 值 | 浅底 | 说明 |
|---|---|---|---|
| `danger` | `#9F2F2D` | `#FDEBEC` | 失败与错误 |
| `ok` | `#346538` | `#EDF3EC` | 成功与通过 |
| `gold` | `#7A5310` | `#FBF3DB` | 需要注意与自动化 |
| `info` | `#1F6C9F` | `#E1F3FE` | 中性提示 |

四者在白底与画布上的实算对比度依次为 7.2 / 6.85 / 6.84 / 5.67 与 6.51 / 6.2 / 6.19 / 5.13，全部通过 AA。

> **终态标识统一为状态圆点**：会话列表、子代理与后台作业的标识都用同一份 `StateDot`，取值与工作台参考实现的状态点一一对应。实心状态在 10px 的槽里画一颗 6px 的圆点，槽宽恒定，换成转圈或别的状态时行内文字不会横跳。
>
> | 状态 | 取值 | 用在哪 |
> |---|---|---|
> | `done` | `--color-ok`（`#22C55E`） | 已完成 |
> | `warning` | `--color-gold`（`#F59E0B`） | 被中断、被杀、被停：按人的意思结束 |
> | `error` | `--color-danger`（`#EC1313`） | 失败 |
> | `idle` | `--color-state-idle`（`#D4D4D4`） | 既没在跑也没结果 |
> | `ongoing` | `--color-text-tertiary` | 在跑：14px 的环加呼吸弧，匀速 1.5s，动画起点钉在时间零点所以同屏同步。旋转落在 `svg` 盒子上、弧的呼吸走 `opacity`，因此全程留在合成器与局部重绘里，不会带动整篇文档重排 |
>
> **状态色的来源**：`--color-ok`、`--color-danger`、`--color-gold`、`--color-state-idle` 四个取值直接采用参考实现的状态色（其 success / error / warn / idle）。标记沿用这四个取值，因此绿、红、琥珀各只有一个标记档：绿 `#22C55E`、红 `#EC1313`、琥珀 `#F59E0B`。**文字**另取可读档：红色文字直接用 `--color-danger`（对白底 4.5:1），琥珀文字用 `--color-gold-ink`（`#B45309`，对白底 5.02:1），标记继续用 `--color-gold`。
>
> **前置状态槽**：行内只有一个状态标记，占前置 16px 槽，优先级与参考实现一致 —— 在跑高于未查看的终态（跑起来之后旧标识让位，停下后还会回来），两者都没有就不占位。置顶标记因此移到行尾，与时间同格，悬浮时让位给操作区；它是**实心**图钉（`PinFillIcon`，路径与描边版 `PinIcon` 同源、只把针身填满），菜单项与悬浮按钮则按置顶状态在实心与描边之间切换。图标本身不发声，名称由外层 `role="img"` 给出。
>
> **绿色只有一个取值**：界面里的绿色一律取 `--color-ok`（`#22C55E`），状态圆点、连接状态点、计划步骤完成点与增量的 `+N` 计数共用它，与参考实现把同一个状态成功色同时用于标记与增量计数的做法一致。代码高亮的字符串绿（`--shiki-token-string`）属于语法色板，文件类型图标里的绿属于第三方品牌色，两者都不受此约束。
>
> **已知取舍**：`#22C55E` 作 `+N` 文本对白底是 2.28:1，低于正文 AA 的 4.5。这是参考实现自己的取值口径（其状态成功色同时承担标记与计数），保留不改。琥珀文字不再走这条取舍：倒计时这类**时间关键文本**必须可读，因此另立 `--color-gold-ink`（`#B45309`，5.02:1）并纳入门禁；`--color-gold` 只承担标记与描边。

## 5. 动效系统

### 5.1 缓动曲线

| 角色 | 值 | 用途 |
|---|---|---|
| `ease-standard` | `cubic-bezier(0.2, 0, 0, 1)` | 通用过渡 |
| `ease-emphasized` | `cubic-bezier(0.2, 0, 0, 1)` | 强调转场 |
| `ease-decelerate` | `cubic-bezier(0, 0, 0.2, 1)` | 入场 |
| `ease-accelerate` | `cubic-bezier(0.3, 0, 1, 1)` | 退场 |

### 5.2 时长阶梯

| 档位 | 时长 | 适用 |
|---|---|---|
| Short | 100 至 200ms，实现取 `140ms` | 图标悬停、按键缩放反馈、涟漪 |
| Medium | 250 至 400ms，实现取 `250ms` 与 `320ms` | 抽屉滑入滑出、输入坞高度伸缩、卡片展开 |
| Long | 500 至 800ms，循环动效不受此限 | 极光流光循环（实现取 1800ms 循环） |

### 5.3 动效铁律

- **只允许对 `transform` 与 `opacity` 做动画**。禁止动画 `top`、`left`、`width`、`height`、`margin`、`padding`。
- **禁止动画 SVG 的几何属性**（`stroke-dasharray`、`stroke-dashoffset` 一类）：它们进不了合成器，实测会让整篇文档每帧重排一次（约 60 次/秒）。旋转一律落在 HTML 盒子（`svg` 元素本身或它的外层 `span`）上，不落在 SVG 内部的 `<g>` 上；呼吸、明暗一律用 `opacity`。
- **转圈只有一份实现**：全站转圈统一走 `.state-spinner`（1.5 秒匀速，旋转落在 `svg` 或外层 `span` 的盒子上），不再使用 Tailwind `animate-spin`，也不另写一条旋转关键帧。同时刻在转的元素数量因此有上界：输入坞工作状态行一枚，加每个进行中的过程行一枚。
- **过程行不铺扫光**：思考、执行、工具这类过程行的运行态由状态转圈与耗时表达；扫光只属于输入坞工作状态行与作业面板的等待行，避免一轮里十几行同时扫光。
- **`visibility` 可以参与过渡，但只作离散翻面**：它是「滑完之后再隐藏、滑入之前先现形」的实现手段，本身不产生逐帧的布局或绘制变化。用它时同一条过渡里必须另有一个真的在动的属性（位移或透明度），不得只翻可见性。
- **禁止** `window.addEventListener('scroll')`；一律用 `IntersectionObserver` 或虚拟滚动自有回调。
- 必须实现 `prefers-reduced-motion: reduce` 降级：位移与缩放全部去除，流式光标静止，自动滚动改为瞬时定位。

### 5.4 流式文本淡入

文字不得生硬逐字刷出。块级单元（段落、标题、列表、引用、代码块、表格）在流式期间新挂上来时做一次轻微的上浮淡入：

```css
@keyframes stream-block-in {
    from { opacity: 0; transform: translateY(4px); }
    to   { opacity: 1; transform: translateY(0); }
}

.stream-block-in { animation: stream-block-in 170ms cubic-bezier(0.22, 1, 0.36, 1) both; }
```

**入场只发生在块级单元上**：段落、标题、列表、引用、代码块与表格各是一个块，位移不会引起行内重排。`display: inline` 的元素上不挂任何 `transform` 动画，50 token/s 的流式正文里那样做等于逐批重排。

流式光标为 2px 竖条，透明度 1s 缓入缓出循环；减弱动效下静止。

### 5.5 思考中流光扫描

等待推理时，占位骨架或输入坞边框呈现渐变平移。**推荐用合成器友好的实现**（位移一个渐变伪元素，而非动画 `background-position`），以保持 60 FPS：

```css
.shimmer {
    position: relative;
    overflow: hidden;
    background: var(--container);
}

.shimmer::after {
    content: "";
    position: absolute;
    inset: 0;
    background: linear-gradient(
        90deg,
        rgba(240, 244, 249, 1) 0%,
        rgba(217, 227, 242, 0.8) 50%,
        rgba(240, 244, 249, 1) 100%
    );
    transform: translateX(-100%);
    animation: shimmer-sweep 1.8s linear infinite;
}

@keyframes shimmer-sweep {
    to { transform: translateX(100%); }
}
```

若确需动画 `background-position`，该例外**仅限此一处**且元素面积必须很小，并在代码注释中标注为非合成器动画。

### 5.6 会话切换的过场

打开一条会话要走两段异步：读历史索引，再逐条订阅回放正文。这段窗口里没有可读的内容，因此**任何中间态都不上屏**：留白是一下白闪，逐段画出来是一串跳动。

| 环节 | 规则 |
|---|---|
| 正文层 | **常驻不重挂载**。换会话只换内容，滚动容器留在原地；重挂载会先丢一次版面再重建一次，那正是可感知的顿挫 |
| 落点 | 在交出正文之前定好并贴底。视口高度变化（指标条换一组读数）也要重新贴底，否则底部会差出几个像素 |
| 上一屏 | 正文就绪前继续显示上一屏，不为一次干净利落的切换加戏 |
| 过渡面 | 打开**慢过 140ms** 才出场；出场时与正文同宽（`max-w-chat`）、同内边距、同间隙 |
| 骨架 | 用户气泡与正文行各自的形状和颜色照排，叠化收起时版面不跳；呼吸走整列一个动画 |
| 停留 | 过渡面亮起后**至少停留 160ms** 再交出正文。慢了才亮、亮了就撤，会让过渡面自己变成一次闪动 |
| 出场与收起 | 出场 75ms，收起（叠化到正文）150ms。方向不对称：出场要利落，收起要连贯 |
| 正文入场 | 8px 上浮 200ms，**只走 transform**；减弱动效下不做位移 |
| 收口 | 历史回放排空即收口；另有 900ms 上限，回放卡住时正文区不会一直停在过渡面上 |
| 同一屏的其他读数 | 指标条的十段、指标条右侧的运行时入口与输入坞的状态行都派生自同一份投影，因此按上一屏一起保持，交接时与正文同一帧替换。投影一空它们就整排消失再整排长回来，那比正文的空档更显眼 |

**过渡面淡出期间内容冻结**：内容与透明度同时变，叠化会读成一次塌陷（先塌成空画布再长出正文）。因此过渡面只在出场时更新自己画什么，收起时保持上一份。

**横向几何也不许抖**：停靠面（右侧栏的 tab 集合与开合形态）按会话持久化，切会话必须与目标切换同一次提交整份换掉。晚一帧会先把上一个会话的停靠面画出去，其中就包括指标条右侧那个展开入口，它一出现就消失，与指标条的塌陷是同一种闪动。

首屏与过渡面是同一层的两种内容：没有正文可看时（还没选会话、新建的空会话，或从首屏点进一条会话）画首屏，两屏正文之间切换且慢过阈值时画骨架，其余情况不盖任何东西。

| 正文 | 细节说明 | **紧跟在问题之后、同一段流内**（不另起一行），12px 三级文本色 |
| 选项 | 选项行 | **一行一个选项，不横排**；整行可点，左右内边距 12px、上下 8px，圆角 12px，1px 描边 `--color-border` |
| 选项 | 行首标识 | 单选为 20×20 序号牌（4px 圆角，底 `--color-surface-sunken`，12px 三级文本色，等宽数字）；多选为 16×16 勾选框 |
| 选项 | 选中态 | 底色 `--color-active`、描边 `--color-border-selected`，行首标识反白（底 `--color-primary`，数字或对勾取白） |
| 选项 | 取消选择 | 再点一次已选中的那一项即取消：单选与多选同一套手感，单选取消后该题回到未答；取消只撤掉这一项，用户填过的自定义回答按原文保留 |
| 选项 | 选项文字 | 标题 13px 主文本色、字重 500；说明跟在标题之后同一段落，13px 三级文本色，**选中行上改用二级文本色**（三级对 `--color-active` 只有 4.16:1，达不到正文 AA） |
| 输入 | 自定义回答 | 多行（2 行）；行首一枚编辑图形（14px 三级文本色），聚焦时描边转 `--color-border-selected` |
| 底部左端 | 翻页 | 多于一道题时出现：左箭头、`当前 / 总数`（12px 三级文本色等宽数字）、右箭头，到边界即禁用 |
| 底部右端 | 动作 | 「跳过」为描边次要按钮；主操作按钮在末题写「提交」，非末题写「下一题」 |

**选项为什么竖排**：选项说明常常是一整句话，横排的标签流会把它挤成一条难读的长条；竖排让每个选项独占一行，选择与它解释的内容一一对应。

**卡片自己回来**：只要这条提问还没结算（含已挂起与等待延长），进入会话、新的提问到达、或点击时间线上的回入口，卡片都重新占住输入坞；收起只对这一次进入会话有效。用户因此不必记着去哪一页点一下，也不会停在「看不见又没法答」的中间态。

#### 6.1.2 固定计划坞

计划有两个展示位，分工不能混：

| 位置 | 内容 | 事实来源 | 默认态 |
|---|---|---|---|
| 时间线单元 | 某一次 `update_plan` 的原子记录 | 该次事件本身 | 收起（一行计数摘要） |
| 固定计划坞 | 当前计划 | 会话级计划投影 | 收起 |

- 固定计划坞钉在输入坞正上方，与输入坞同宽（同一份 `max-w-chat` 与水平内边距），随会话切换重挂载，展开态不跨会话沿用。
- 计划坞表达的是「正在执行的这个计划」：只要有轮次在跑就照常占位；整轮收口即随之撤下，不留上一轮的旧进度。时间线单元保留每次更新的原子记录，不受影响。
- 没有计划（投影为空或零步骤）时整块不渲染，不留空壳也不占高度。
- 两处渲染同一份计划卡（图标 + 标题 + 计数摘要 + 折叠箭头 + 步骤列表），只有默认展开态不同，因此共用一处实现而不是各写一遍。
- 步骤状态点沿用统一状态语言：已完成取 `--color-ok`、进行中取进行态转圈、失败取危险色，待处理与已跳过为静息灰点。
- 展开方向朝上，且它长期占位在输入框上方，因此默认收起是常态而不是特例。

### 6.2 视口贴底与打断

- **自适应锁定**：用户位于底部时，流式输出期间视口严格绑定底部。
- **主动打断**：用户向上滚动使距底超过 **80px** 时立即解除锁定，同时右下角平滑浮出「回到最新」微圆角浮动按钮；点击后瞬时归位并恢复锁定。

### 6.2 附件卡

粘贴、拖放、系统选择器与大段文本落盘四条路径都产出同一张卡：**类型徽标 + 文件名 + 类别与体量**。输入区与用户消息气泡共用这一种形态，不做第二套附件外观。

| 属性 | 值 |
|---|---|
| 尺寸 | 宽 224px，高 52px |
| 内边距 | 左 8px、右 4px，徽标与文字间距 10px |
| 圆角 | 12px（`rounded-md`），0.5px 发丝描边，底色 `--color-surface` |
| 徽标 | 32×32，圆角 8px，底 `--color-surface-sunken`；图片放真实缩略图，其余走共用文件图标表 |
| 文件名 | 13px / 20px，`--color-text-primary`，单行截断 |
| 元信息 | 11px / 19px，`--color-text-tertiary`，形如 `Excel · 5KB`；判不出类别或没有体量时该项省略，整行都不成立就不渲染这一行 |
| 移除 | 20×20，常显（输入区）；消息气泡里只读，不显示移除 |
| 悬浮 | 只换底色；图片点击放大查看，文件点击在右侧栏打开 |

**徽标不新造图标语言**：类别徽标复用文件树与侧栏同一份图标表，图片用真实缩略图；不引入绿色 Excel 之类该产品没有的色块。

### 6.3 消息操作栏

- **用户消息**：悬停或长按时在右侧显示轻量操作栏（编辑问题、重新发送）。
- **助手回答**：回复完成后底部显示轻量操作栏（复制 Markdown、导出 Markdown、朗读回复）。
- **朗读微动画交互**：朗读按钮在合成准备期翻转为阻尼转圈（点击可取消），播放期换成停止图形；「正在朗读」四个字与实测振幅驱动的 `VoiceWave` 声波紧跟在喇叭之后出现，读的是「这一枚按钮正在做的事」，不另起一行也不改变页脚高度。顶栏会话自动朗读开关与设置人设音色试听行复用同一份 `VoiceWave` 基元表达发声态。
- **状态反馈**：点击复制后图标在 150ms 内翻转变为对勾，停留 1.5 秒后回滚。
- **时间标记**：用户气泡与助手操作条都在操作图标左侧给时间（12px，三级文本色，等宽数字），两处同一写法。档位按距当前时间的远近切换：一分钟内 `刚刚`、当天 `时:分`、昨天 `昨天 时:分`、同年更早 `月日 时:分`、跨年 `年月日 时:分`；判定用本地日历日而不是 24 小时窗口，跨零点后昨天的消息就显示昨天。

### 6.4 手势与触觉（仅移动端形态）

长按消息触发中度触觉并弹出气泡菜单；轻击品牌标识伴随轻度触觉与 `scale(1.15)` 回弹；生成图片支持共享元素转场到全屏查看。**桌面端不适用，仅在窄窗触屏形态下按需启用。**

### 6.5 技能指令高亮

正文里**精确命中已安装技能名的 `/name`** 要看得见，输入框与用户消息气泡两处同一个口径：

| 规则 | 值 |
|---|---|
| 认哪些 | 斜杠落在正文开头或空白之后，名字由词字符与连字符组成，且它后面是空白或正文结束；名字必须精确等于已安装技能名 |
| 不认哪些 | `/tmp/x`（后面还有路径）、`/plan.md`（后缀黏着）、`看/看`（斜杠前是词字符）：它们都是普通文本 |
| 颜色 | `--color-skill-ink`（`#0B57D0`），对白底与用户气泡底都过正文 AA，见 §2.5 |
| 名单来源 | 与指令候选同一份已安装技能清单，全应用共用一次读取；清单未就绪时不上色，就绪后自己回来 |
| 输入框 | textarea 无法只给部分文字上色，因此用同一套度量再画一层底衬，输入框文字取透明；输入法组合期间底衬让位、文字交回输入框（组合下划线是输入法自己画的），同时不重新量高度：拼音串只是输入法的中间态，它一折行输入坞就长高一行，上方正文会被整块顶走再落回，读起来就是一直在跳；确认之后再按正文量一次 |
| 两层同宽 | 底衬与输入框必须逐字同宽，任何一层先折行都会让光标行与选区压在错位的行上。输入框超过 6 行后出现 8px 滚动条并占掉内容宽度，因此两层都常驻同一条滚动条凹槽（`scrollbar-gutter: stable`）：滚动与不滚动两种状态下内容宽度都相等 |

### 6.6 网页链接占位

粘贴一段 http 或 https 地址时，草稿里只留一个短占位符，地址本身收进输入区上方的链接卡。这与 TUI 的附件占位是同一套语义：界面上看见的是占位，提交时展开回原文，模型拿到的仍然是一个完整 URL。

| 规则 | 值 |
|---|---|
| 认哪些 | 只认 `http://` 与 `https://` 开头的地址。地址在空白、引号、尖括号与中文处截断；结尾的句读与不成对的右括号剥掉（`（见 https://x.com/a）。` 里的地址只取到 `/a`），结尾的问号保留：它可能是查询串的一部分，剥掉就等于改了粘进来的地址 |
| 占位符 | `[站点]`，站点取去掉 `www.` 的主机名，例如 `[toutiao.com]`。同一页重复粘贴同一地址复用同一个占位符；同站的不同地址依次加 ` #2`、` #3`；与草稿里已有的同样文字冲突时同样加后缀 |
| 底衬 | 占位符在输入框底衬里取 `--color-text-link`，底 `--color-surface-sunken`，4px 圆角。**不加内边距**：占位符与光标共用同一套字位，任何横向留白都会让光标与文字错开 |
| 链接卡 | 与附件卡同一份几何（224 × 52，12px 圆角，0.5px 发丝描边，底 `--color-surface`）：徽标是 32 × 32 的地球图形，主行是去掉查询串与井号后的站点与路径，次行写「网页链接」，移除按钮常显。整卡的原生提示给完整地址 |
| 提交 | 发送前把占位符展开回原始地址，因此用户气泡、重新发送、复制消息与模型看到的都是那段 URL，不是占位符 |
| 气泡 | 用户消息里的地址渲染成一枚行内芯片：地球图形 12px 加站点与路径，底色 `--color-surface`，链接色取 `--color-text-link`，单行截断。点击用系统浏览器打开，完整地址挂在原生提示上 |
| 打不开 | 打开失败时把地址复制到系统剪贴板，并在原生提示里说明；输入坞同时给一行 danger 回执，气泡里的芯片没有回执位，因此只更新提示 |
| 只走粘贴 | 只有粘贴会做占位，逐字键入的地址保持普通文字。占位是粘贴这一动作的回执，不接管正在写的正文 |
| 草稿里的复制 | 从输入框复制草稿得到的是占位符本身；消息发出之后，复制消息与重新发送取的都是消息原文（完整地址）。两者口径不同是有意的：草稿里没有第二条可复制的正文 |
| 子代理输入条 | 紧凑变体不做占位（它没有附件条），地址按原文落进正文 |

链接卡与附件卡共用同一个条目卡外壳，二者只有徽标与两行文字不同。用户气泡里的技能指令高亮与链接芯片互不抢位：先认链接，剩下的文字再按 §6.5 认技能。

## 8. 令牌命名约定

| 场景 | 命名 |
|---|---|
| 原型 CSS | `--<角色>`，例如 `--surface`、`--ink-1`、`--r-md` |
| 生产前端（Tailwind 4 `@theme`） | `--color-<角色>`、`--radius-<角色>`、`--ease-<角色>`，由框架前缀规则生成工具类 |

两套命名必须指向本文件的同一组值。生产前端的令牌必须落成**单一 CSS 文件**，禁止把颜色或间距散落在组件内。

### 8.1 组件内零字面量（硬门禁）

组件里不得出现颜色字面量（`#rrggbb`、`rgba(...)`）与重复的尺寸常量：颜色、字号、正文列宽一律从 `tokens.css` 读取，新增取值必须先在令牌文件里成角色，再在组件里引用。

- SVG 上取色用**内联样式**（`style={{ fill: 'var(--color-x)' }}`）而不是呈现属性：呈现属性上的 `var()` 在部分引擎不生效，内联样式是标准 CSS 声明，任何支持自定义属性的引擎都能解析。
- 只能吃字面量的第三方库（图形引擎的 `themeVariables` 等）在运行时读令牌，不落第二份色板副本。
- **字号令牌的名字不得与任何 `--color-*` 同名**：`text-*` 同时命中字号与颜色两个命名空间时按颜色解析，字号会被静默忽略（`--text-bubble` 曾与 `--color-bubble` 撞名，`text-bubble` 生成的是 `color` 而不是 `font-size`）。新增字号令牌后必须核对生成物确实是 `font-size`。
- **行高由位置决定还是由角色决定**：整行正文用带行高的角色档；紧凑行内标签用角色档加显式 `leading-*`。Tailwind 的 `leading-*` 通过 `--tw-leading` 参与合成，会压过角色档自带的行高，因此两者可以并存。

**唯一豁免**：`components/conversation/fileIcons.tsx` 里的第三方语言与工具标识，那是他人商标的美术还原，色值是资产本身，不是本设计系统的决策。

## 9. 侧栏几何与排版规范

本节是对 §1 与 §3 在**侧栏与设置页**范围内的具体化；与之冲突时以本节数值为准。

### 9.1 侧栏宽度

| 常量 | 值 | 说明 |
|---|---|---|
| 最小宽度 | **264px** | 拖拽夹取下限 |
| 最大宽度 | **420px** | 拖拽夹取上限 |
| 默认宽度 | **280px** | 首次打开、双击把手复位 |

拖拽把手是**不可见的 8px 命中区**（左右各外扩 4px），只保留列宽光标这一处可见反馈，不额外绘制把手或分隔条。侧栏**不显示滚动条**：滚动能力保留，但不绘制轨道与滑块。折叠后为 24px 图标列、左右各 16px 内边距（合计 56px）。

| 元素 | 值 |

| 工作区与会话标题 | 14px / 20px |

| 行内元素间距 | 6px |
| 行左右内边距 | 8px |
| 会话缩进 | 14px 每层 |
| 标题与会话时间之间 | 额外 6px |

工作区行常态显示文件夹图标（**展开态用展开文件夹**，当前工作区用强调色），悬浮时让位给实心三角展开箭头。

### 9.3 设置页排版

| 元素 | 字号 |
|---|---|
| 弹窗标题 | 16px |
| 二级导航项 | 14px |
| 配置项标签 | 14px |
| 配置项说明 | 12px |
| 小号按钮与输入类控件 | **13px** |

每个配置项为「标签 + 一行弱化说明」，控件右对齐；配置行不使用分隔线，靠行高与留白区分。

## 10. 浮层与悬浮规范

### 10.1 菜单定位

菜单**挂到 `body`** 并以固定定位摆放，因此不受祖先容器的 `overflow` 裁切，夹取基准是**窗口**而不是侧栏：

1. 锚点下方间距 **4px**；
2. `align=start` 时与锚点左缘对齐，`align=end` 时与锚点右缘对齐；
3. 水平与垂直都以 **12px** 边距夹取到窗口内。

**关闭条件**：点击菜单外部、按 Esc、滚轮滚动。滚动时关闭而不是跟随重排：跟随重排需要滚动监听，而 §5.3 的动效铁律禁止滚动驱动逻辑。

### 10.2 行悬浮卡

指针停在工作区或会话行上时，在**行的右缘外 8px** 展开信息卡，顶端与行对齐；卡片底部按 8px 边距夹取，靠近窗口底部时整体上移。

| 属性 | 值 |
|---|---|
| 宽度 | 244px |
| 内边距 | 12px 16px |
| 圆角 | 12px |
| 底色 | `#2C2C2E` |
| 标题 | 14px / 20px，`#FFFFFF` |
| 次要行 | 12px / 16px，`#CFD3D6` |
| 行间距 | 8px |

卡片**不接收指针事件**，指针离开行即收起，不会因卡片抢焦点而闪断。

### 10.3 标题跑马灯

单行标题被截断时，指针停在行上让标题匀速走到末尾：

- 溢出不足 **8px** 不启动（几个像素的位移会被读成抖动）；
- 速度 **0.03px/ms**，慢到能在移动过程中读清文字；
- 走到末尾即停在末尾，不来回摆动；
- 两端 **12px 渐隐**：离开起点时左端渐隐，右侧仍有内容时右端渐隐，走到末尾后右端渐隐抬起；
- 遵循「减少动效」偏好：直接落到末尾，不做动画。

### 10.4 行内操作区

行内操作图标**只在悬浮时出现**，并在出现时顶替原本的时间显示。

实现上必须用**显示切换**而不是可见性切换：`visibility: hidden` 仍然占据布局宽度，会让操作图标常驻吃掉标题空间，导致静止时标题提前被截断。菜单展开期间由激活态强制常显，因此不会连带销毁已打开的菜单。

> **消息操作条是这条规则的例外**：助手正文下方的复制与下载是正文的固定出口，**常显**不隐藏，也不顶替任何读数。它们不占标题宽度，藏起来只会让人先猜哪里能悬浮。本条「悬浮才出现」只约束列表行里与时间同格的图标。

### 10.5 指标浮层

指针停在指标条的单个读数上时，在该读数右缘外 **8px** 展开一张浅色指标卡；几何与开关行为与 §10.2 的行悬浮卡**同一份实现**，只换皮肤。

| 属性 | 值 |
|---|---|
| 宽度 | 268px |
| 内边距 | 12px 14px |
| 圆角 | 12px |
| 底色 | `--color-surface`，0.5px 中性描边 |
| 阴影 | Level 2（`shadow-panel`）|
| 标题行 | 左「标签 + 数值」13px，右侧读数 12px 三级文本色 |
| 色带 | 高 6px 胶囊，底 `--color-surface-sunken` |
| 分段色 | 同一蓝色梯度的 25% / 55% / 100%（`--color-text-link`） |
| 差额色 | `--color-state-idle`，明示它不是估算的一部分 |
| 区块间距 | 图例行 6px，区块之间 10px |

- 估算值一律带 `~`，实测值不带；色带的彩色部分恒等于标题里的已用比例，两处读数不会互相打脸。
- 卡片不接收指针事件，指针离开入口即收起；没有观测的读数不进浮层，也不画空卡，缺观测必须显式说明。

### 10.6 文本选择与右键菜单

**正文默认可选**：标签、说明、弹窗正文、列表行文字都允许拖选、双击选词与 `Ctrl+C`。需要屏蔽选区的只剩控件本身（按钮、菜单项、复选框标签、可拖拽行、代码行号槽），它们各自声明 `select-none`；不存在「整个窗口不可选」这一档。

**右键菜单是一条全局机制，不是各页面自己实现的东西**：全应用只挂一个菜单宿主，新增页面自动获得同一套行为。

| 落点 | 菜单 |
|---|---|
| 可编辑宿主（文本型 `input` / `textarea`） | 撤销、恢复、剪切、复制、粘贴、全选六项，与输入坞同一份文案与分组 |
| 其余位置 | 只有一项「复制」，且只在真有选区时出现；没有选区时不弹菜单 |

- 条目文案、快捷键与分组线只有一处定义（`editingCommands`），输入坞的编辑器菜单与全局宿主共用，因此两处读起来完全一致。
- 选中的文本在**按下右键的这一刻**取下来：菜单按钮会拿走焦点，等点击时再读选区只会拿到空串。
- 系统自带的 webview 菜单被统一压掉：这是桌面应用而不是网页，「刷新 / 另存为 / 打印 / 检查」在这里既用不到，也会让人误以为界面是浏览器页面。
- 菜单层级取所有浮层之上（模态 1000、下拉 1100，菜单 1200）：弹窗与浮层里的正文同样要能右键。
- 组件需要自己的菜单时，在自己的 `onContextMenu` 里走 `useContextMenu().open`：那一步会阻止冒泡，文档级的兜底层据此让位，两套菜单不会同时出现。

### 10.7 输入坞候选菜单

输入 `@` 或 `/` 时，在输入坞卡片上方弹出候选菜单（文件引用与斜杠指令共用同一份实现）。它是**浮层而不是卡片里的一块**：候选条数一变，卡片高度就跟着变，输入框会被顶得上下跳；浮层展开与收起都不改卡片版面。

| 属性 | 值 |
|---|---|
| 位置 | 贴着卡片**上沿**，间距 4px，与卡片同宽（§10.1 的「锚点下方」说的是列表行菜单；输入坞在窗口底部，因此这一处向上展开） |
| 与窗口上沿 | 至少留 12px；高度上限 400px，贴顶时下限 80px，超出在菜单**内部滚动** |
| 卡片 | 内边距 4px，圆角 8px（`r-sm`），0.5px 发丝描边，Level 2 阴影；滑块可见（`scroll-visible`），长列表才看得见「下面还有内容」 |
| 行 | 最小高 34px，内边距 6px 8px，圆角 4px（`r-xs`），13px / 20px 正文 |
| 行内容 | 左侧候选名（最多占 40% 宽，单行截断），右侧说明**右对齐**、12px 三级文本色、单行截断；名称因此始终从同一条竖线开始 |
| 高亮 | 键盘与指针共用**一个**下标，只有一层 `--color-hover` 底色；指针走 `mousemove` 换高亮，行本身没有 `:hover` 底色，因此不会出现「指针停一行、键盘选另一行」 |
| 采纳 | 指针**按下即采纳**（阻止默认行为，输入框因此不失焦，采纳后可以直接接着打字）；键盘 Enter 或 Tab 采纳，上下键循环移动 |
| 收起 | Esc 与 Shift + Tab；指针落在菜单与卡片之外。**滚轮不关闭**：这里的列表自身就要滚（§10.1 的滚轮关闭针对不滚动的菜单） |
| 打开条件 | 光标之前那一段里存在可用的斜杠或 `@`：正文开头、空白之后、或标点之后（`看/看`、`src/util`、`https:/go`、`a//go` 都不弹）。没有候选时整块不渲染，不留空壳 |
| 候选排序 | 前缀命中优先，其次命中窗口更紧凑、更靠前，最后保持来源顺序；查询词按有序子序列匹配，因此 `/bws` 能命中 `browser-skill` |
| 无障碍 | 列表 `role="listbox"`，行 `role="option"`，输入框用 `aria-expanded` / `aria-controls` / `aria-activedescendant` 指向当前行；焦点始终留在输入框 |

**内置指令与技能同列不同路**：`/mcp` 这类内置指令排在候选最前（清单只有 `conversation/builtinCommands` 一处），采纳后同样把指令名写进正文；提交时若正文恰好是一条内置指令，由界面自己执行、不进会话，回执落在输入坞上方那一行（`已重载 MCP：3 台全部正常` / `2 台正常，1 台异常`）。带参数的 `/mcp 看这个` 按普通消息发给模型。

**指令的展开型回执是一条上沿浮层**：`/mcp` 除了那一行回执，还在输入坞上沿摊开一张清单卡（与候选菜单同一位置、同一宽度，`Z_MENU`）。卡片 surface 底、发丝描边、14px 圆角、Level 2 阴影；标题行 13px 写「MCP 服务器」加「N 台正常 · M 台异常」，右端是 28px 关闭按钮；正文高度上限 260px、超出在卡片内部滚动（`scroll-visible`），因此展开收起都不改输入坞版面。逐台一行：成功的写服务器名（14px 500）与「N 个工具」（12px 三级），下一行是等宽 12px 的工具名、最多两行；失败的写服务器名、危险色「加载失败」与失败原因，并排在清单最前。下一次提交或关闭按钮即收起。

**收起是「这一条不再弹」，不是「以后都不弹」**：Esc 记住当前这一条 token 的身份，光标不动、正文不变时它不回来；多打一个字或这条 token 消失（打成空格、删掉斜杠），记忆立即作废，候选照常出现。

## 11. 条目卡片

同类条目集合（MCP 服务器、技能等）统一使用卡片列表：

| 属性 | 值 |
|---|---|
| 描边 | 0.5px，浅描边令牌（`rgba(0,0,0,0.10)`） |
| 圆角 | 16px |
| 悬浮 | **只换底色**，边框与圆角不变 |
| 网格 | 两列自适应，间距 12px |
| 标题行 | 左侧名称与标签，最右侧等宽标识 |
| 底部 | 左侧次要信息，右下角**唯一的「查看配置」入口** |

其余操作（编辑、移除）一律收敛进「查看配置」弹窗，卡片本身不再堆按钮。

三者为**独立可复用组件**：卡片列表、条目卡片、详情弹窗。新增卡片集合只需声明数据与详情字段，不必再写一套列表与详情视图。

### 11.1 目标看板与目标卡

目标看板是条目卡的一个**分栏变体**，不是第二套卡片语言：卡片仍取条目卡外壳（`EntityCard`），采用 `.card-interactive` 光学抬升与弹簧按压反馈，只在既有信息位上换内容。界面只保留产品态文案，不展示内部实现术语或轮询状态提示。

| 插槽 | 默认 | 目标卡取值 |
|---|---|---|
| `leading` | 不渲染 | 状态点（`StateDot`），与标题首行基线对齐 |
| `badges` | 可选标签 | 语义状态胶囊（`Chip`：进行中取 `accent`，等待中与已暂停取 `warning`，已完成取 `ok`，已失败取 `danger`，其余取 `neutral`） |
| `statusCue` | 不渲染 | 下沉内嵌进展带，区分「等待」告警与「下一步」动作，最多两行 |
| `metaNode` | 纯文本 `meta` | 文件夹图标 + 工作区名称（全局目标显示「全局」）+ 最近活动时刻（11px 等宽数字） |
| `actionIcon` | 齿轮 | 能进会话时向右箭头，只能看详情时清单图形，悬浮伴随微右移反馈 |

字段映射自上而下读作一句话：**状态点与标题（最多两行）→ 语义状态胶囊 → 去重后的目标预览 → 下一步或等待进展带 → 工作区与活动时刻 → 唯一入口**。当目标预览与标题完全一致时不重复渲染第二遍；状态文案只有中文，界面不出现后端枚举。

**看板几何。**

| 元素 | 值 |
|---|---|
| 版心 | `PageShell` 全宽满高（`fill` + `wide`），工具栏左侧为定宽搜索框（可一键清空）与「全部 / 未完成 / 已结束」分段控件，右侧为 12px 等宽统计读数 |
| 栅格 | 容器查询：默认 1 列，520px 两列，760px 三列，1000px 四列；间距 14px，四栏等高拉伸（`items-stretch`）铺满舞台余下高度 |
| 栏目 | 下沉面（`--color-surface-sunken`）+ 发丝描边 + 12px 圆角（`rounded-md`），内边距 12px，卡间距 10px |
| 卡片 | 固定 148px 高度（`uniformHeight`）：单行标题 + 两行目标预览槽 + 单行行内进展提示（无内嵌边框盒）+ 36px 底栏，保证全看板卡片尺寸完全一致 |
| 层级 | 只有两层：下沉栏目底板 + 浮起卡片。禁止再套第三层 |
| 滚动 | 栏目内容超出时在列内或展开后滚动；长列表靠「显示其余 N 个」展开 |
| 栏目头 | 左侧栏目状态点 + 标题 13/20 500，右侧下沉计数胶囊 11/16 等宽 |
| 空栏目 | 在等高栏目正中居中呈现「暂无目标」 |
| 渲染上限 | 每栏 20 张，超出给展开按钮；四栏合计即初始挂载上限 80 张，展开后仍受服务端 256 条上限约束 |
| 计数 | 总数取本次读取回执的 `returned`，并列未完成与已结束；达上限时补一句「已达上限，仅显示 256 个」。不写「最近」，因为服务端按更新时间升序出页 |

**执行会话视图。** 页内进入，自带 40px 原生可拖拽顶栏（返回看板、状态点与标题、语义状态胶囊、工作区与活动时刻、详情入口；自动避让右上角窗口控制键，支持 `Esc` 快捷返回），与看板态互斥，因此任何时候只有一条顶栏。下方采用全宽满高纵向工作台布局：顶部为全宽目标概览面板（无执行记录时默认展开，展开态以三列等宽等高网格并列呈现「目标说明」「执行步骤」「验收标准」三张纯净浅底子卡，仅在标题前置微图标与状态点上作低饱和三色点睛，正文与标题全部保持高可读中性墨色，与详情弹窗共用 `GoalContractSections`），下方为占满剩余高度的「执行记录」面板（承载逐字稿流或居中空态，**不渲染输入坞**）。空态按执行状态分流：排队中显示「正在等待调度执行」，其余显示「暂无执行记录」。

**焦点连续性。** 进入会话视图焦点落到返回按钮；返回后回到来源卡片。轮询在 tick 内检查 `document.visibilityState`，隐藏时跳过本轮，不新增事件监听。

## 12. 右侧停靠栏与文件预览

> **现行几何见 §0.4/§0.5**：tab 条与主区顶栏统一 36px，末格控件 28px，分栏可容阈值按真实控件簇重算为 416px；终端必须使用从令牌派生的浅色主题，不使用 xterm 默认黑底。本节其余交互与内容责任继续有效。

### 12.1 tab 条

一格一条 tab 条，**条本身就是这一格的上边**，不再单独画标题行。

| 元素 | 值 |
|---|---|
| 行高 | 38px（28px 内容带 + 10px 顶部内边距），与主区域指标条同高 |
| 圆角 | 8px（`r-sm`） |
| 左右内边距 | 左 10px、右 6px，元素间距 4px |
| tab 胶囊 | 宽 80 至 170px，左右内边距 10px，高 28px，字号 13px |
| 关闭按钮 | 20×20，绝对定位在胶囊右上角 4px；悬浮、聚焦与选中态可见 |
| 标题让位 | 关闭按钮压在标题末端时不换行也不省略：常态遮罩末 16px，悬浮或选中时提前到末 30px 处淡出 |
| tab 分隔 | 相邻胶囊之间一条 0.5×14px 发丝线，仅作分组留白 |
| 选中态 | **填充底色加主文本色，不画描边**；未选中无底色，悬浮换底色 |
| 进度与状态 | 一律不画在 tab 上，状态由所在面板正文承担 |

**tab 图标按类型取图形**：文件页用目录图形，资源页按扩展名取类型图形（代码、Markdown、图片等），取不到类型时用通用文件图形。图标是识别辅助，不承载唯一信息。

### 12.2 末格控件簇

控件只画在**最后一格**的末端，顺序固定，不做浮动：

| 顺序 | 控件 | 图形 | 尺寸 |
|---|---|---|---|
| 1 | 分栏 / 并栏 | 一列拆两列 | 24×24 按钮，图形 15px |
| 2 | 全屏 / 退出全屏 | 四角外扩 / 四角内收 | 同上 |
| 3 | 收起面板 | 面板轮廓，分隔线落在右缘 | 同上 |

三个控件取三级文本色，悬浮只换底色，不画边框。**不使用文字按钮**：文字宽度随语言变化，会把控件簇挤成不确定宽度。

### 12.3 分栏可容判定

一格的硬需求是「一个最小宽度的 tab 胶囊加这一格自己的内边距」，末格再加控件簇的宽度；两格相加才是可分栏的宽度。达不到时**禁用按钮并说明原因**，不做「点了没反应」。

| 常量 | 值 |
|---|---|
| 胶囊最小宽度 | 100px |
| 一格内边距 | 12px |
| 末格控件簇 | 78px |

### 12.4 收起与展开的分工

**默认折叠**：停靠栏不占正文宽度，展开与否由用户当下这一手决定。开合触发与行为规范：

| 时机 | 行为 |
|---|---|
| 用户点展开入口 | 展开；整列还是空的，同时播种默认页（引导页） |
| 在正文里查看文件（打开资源） | 同一步里展开并落到该资源，**不先塞默认页**：新展开的面板只显示它打开的东西；这一格只有默认页时默认页让位，不并排成两个 tab |
| 用户点收起入口 | 收起；保留全屏形态，下次展开回到全屏 |
| 关掉整列最后一个 tab | 收起整列，并**一起退出全屏**：重新展开只回到贴靠形态，不再把整个窗口让给刚播种的默认页 |
| 关掉最后一个内容 tab（整列只剩默认页） | 同样收起整列并退出全屏：默认页不是内容，它跟着整列一起收，重新展开时原样回来 |
| 自动全屏生效时点全屏控件 | 改为收起整列并退出全屏：贴靠态无处可退，否则按钮点了没有任何可见变化 |
| 默认页独占停靠面 | **不画关闭入口**，模型也直接拒绝：关它等于关整列，这一手势归收起按钮 |

**开合与全屏随会话持久化**：重启后回到离开时的样子；**从未打开过的会话是折叠的默认形态**。停靠面内容（tab 集合、分栏比例、栏宽）同样跨启动保留，因此再次展开时上次看的东西还在原处。

**收起保持挂载，贴右缘滑出**：停靠栏收起时**不卸载内容**，只把占位宽度收成 0，面板本体保持真实栏宽整体右移一栏宽滑到窗口右缘之外，滑完之后再翻可见性；展开是同一条位移的反向。因此文件树的展开态、预览的滚动位置与栏内的选中项都跨开合保留，开合在两种呈现形态下都是「从那条边滑出、滑回」这一个手势。

| 状态 | 占位宽度 | 面板位移 | 可达性 |
|---|---|---|---|
| 展开（贴靠） | 面板宽 | `translate-x-0` | 常态 |
| 展开（全屏） | 0（覆盖窗口，不占正文宽） | `translate-x-0` | 常态 |
| 收起 | 0 | `translate-x-full` | 移出可访问性树与 Tab 序列，且不接收指针事件 |

位移**只走 transform**，宽度**不做过渡**：正文列的宽度瞬间让出与收回，动的是内容。可见性跟着同一条时长过渡：`visible` 到 `hidden` 在位移走完之后才翻，滑出全程看得见；`hidden` 到 `visible` 立刻翻，滑入不迟一帧。

**全屏形态只在展开态生效**：手动全屏后收起时，全屏这一位仍然保留（下次展开回到全屏），但收起态的渲染一律走贴靠形态（零宽加右移），否则收起后会留下一层盖住整窗的浮层。

**焦点连续性**：只有一种情况移动焦点，即**刚才获得焦点的节点随这次提交从文档里消失**。触发入口自己消失时焦点要续上，触发入口还在时一律不抢：

| 手势 | 焦点落点 |
|---|---|
| 点主区右上角的展开入口 | 入口随展开消失，焦点落到活跃格的活跃 tab 的**第一个可聚焦元素**；正文里没有可聚焦元素时退到该 tab 的胶囊 |
| 关掉焦点所在的 tab | 该 tab 的关闭按钮或正文节点消失，焦点落到仍然可见的活跃格，规则同上 |
| 关掉整列最后一个 tab | 整列已收起，内部没有可落点，焦点落到主区右上角重新出现的展开入口 |
| 点面板自己的收起按钮 | 只切状态，**不动焦点** |
| 从正文里点开一个文件 | 触发入口还在文档里，**不动焦点**：用户的位置不该被打断 |

**同一件事不在两处各摆一个开关**：

- 面板展开时，收起入口只在停靠栏控件簇的第 3 个位置；
- 面板收起后，停靠栏整列不占宽度，主区域右上角出现展开入口。

两处用**同一个图形的镜像**表示同一种操作，因此用户不必学两套语义。

### 12.5 文件查看页

文件查看页与文件树、改动对比页同属右侧停靠栏的 tab 类型，排版规范：38px 工具栏压在 tab 条之下（两条 38px 相加 76px，与主区域会话头的分割线同高），下面是正文自己的滚动区。

工具栏从左到右：

| 位置 | 内容 |
|---|---|
| 路径 | 弹性占位，右外边距 12px；目录三级文本色、文件名主文本色，整条路径挂在 `title` 上 |
| 呈现方式 | 候选多于一种时才出现：按钮写当前呈现方式的名字（代码 / Markdown / 纯文本），宽至 160px 后截断 |
| 换行 | 只有当前呈现方式支持换行时才出现；按下态用「取消换行」图形，未按下用「自动换行」图形 |
| 重新读取 | 重新读这一份文件，不动布局与其他 tab |
| 用其他应用打开 | 分裂按钮，见 §12.9；排在最后，紧贴右缘 |

| 属性 | 值 |
|---|---|
| 行高 | 38px |
| 内边距与间隙 | 左 16px、右 6px，元素间距 4px |
| 下边框 | 0.5px，`--color-border-strong` |
| 工具按钮 | 28×28，圆角 8px，图形 15px，三级文本色，悬浮换底色并转主文本色 |
| 复制回执 | 图标 150ms 内变对勾，停留 1.5 秒后回滚 |

**呈现方式是动态判定的**：同一个文件可能有多种看法，候选**按后缀**从渲染器表里挑，顺序即优先级与菜单顺序 —— 纯文本（兜底）、Markdown、HTML、图片、PDF、Office、表格、代码。Markdown 文件的候选是「Markdown → 代码 → 纯文本」，`.svg` 同时给出「图片」与「代码」，二进制后缀（`.png`/`.pdf`/`.docx`）只给那一种、**不追加纯文本兜底**（读不出文本的后缀摆一个「纯文本」只会得到一屏乱码）。一个后缀连兜底都没有时（视频、压缩包、`.xlsx`）返回空表：**一次读取请求都不发**，直接把「暂时无法预览」与「用其他应用打开」摆在中间。

**呈现方式跟 tab 走**：用户选过之后写进布局（`RailTab.viewer`），切 tab、收起面板、重启都还在，不会在他切回来时变回默认。

**路径栏显示绝对路径**：后端在读取结果里同时给出相对路径与绝对路径，查看页显示后者。溢出时在**左端**固定 28px 渐隐：被裁掉的是路径开头，文件名始终看得见。

**代码正文自带一行头部**：左侧是语言徽标（等宽 11px，三级文本色；判不出语言时写「代码块」），右侧是复制按钮（24×24）。这一行的底色是透明的 —— 正文本来就坐在面板自己的底色上，聊天里的代码卡灰底只属于聊天。

**行号是 CSS 计数器，不是 DOM 节点**：

| 属性 | 值 |
|---|---|
| 槽宽 | `max(2, 行数位数)ch`，作为 `--code-gutter-width` 传给正文 |
| 行文本缩进 | `calc(槽宽 + 12px)` |
| 行高 | 正文 11px / 19px 等宽（`text-code`） |
| 号色 | 三级文本色，右对齐 |
| 选区 | 计数器内容不进选区，勾选正文复制出来的内容里天然没有行号 |
| 正文内边距 | 16px |

**代码在自己的滚动区里滚**：正文上沿那一行是滚动区的兄弟节点，因此代码滚动条从头部之下才开始，滚源头几行时语言徽标与复制按钮一直看得见。

**纯文本没有行号槽**：行号属于代码，不属于任何普通文本文件。

**八种渲染器与它们的读取方式**：

| 渲染器 | 认领的后缀 | 读取 | 换行 | 正文自带的一行 |
|---|---|---|---|---|
| 纯文本 | 兜底（任何未被二进制声明的后缀） | 文本 | 是 | 无（行号不属于文本文件） |
| Markdown | `md` `markdown` | 文本 | 否 | 无 |
| HTML | `html` `htm` | 字节 | 否 | 「HTML 文档预览」 |
| 图片 | `png` `jpg` `jpeg` `gif` `webp` `bmp` `ico` `svg` | 字节 | 否 | MIME 类型 + 缩放控件 |
| PDF | `pdf` | 字节 | 否 | 页数 + 缩放控件 |
| Office 文档 | `doc` `docx` `ppt` `pptx` | 不读 | 否 | 无（整屏降级态） |
| 表格 | `csv` `tsv` | 文本 | 否 | 「N 行 × M 列」 |
| 代码 | 能着色的后缀（与高亮引擎共用一份来源） | 文本 | 是 | 语言徽标 + 复制 |

**字节读取与文本读取是两条路**：图片、PDF、HTML 必须拿到**未解码的字节**（按文本读会把非 UTF-8 的部分换成占位符，画出来的图就是坏的），因此后端另有一条 `workspace_read_bytes`，上限 12 MiB（文本那条是 2 MiB），返回 base64 与由扩展名判定的 MIME。

**各渲染器的内容责任**：

| 渲染器 | 画法 |
|---|---|
| HTML | `Blob` 地址交给 iframe，沙箱**只放开脚本**：文档自己的 JS 照常跑，但它是独立来源，拿不到工作台的存储与身份；相对资源不加载（预览的是这份文件，不是它所在的目录） |
| 图片 | data 地址居中摆放，缩放控件给「缩小 / 比例（含适应宽度）/ 放大」，档位 50%–200% |
| PDF | pdfjs 逐页画进 canvas，页面**先摆占位尺寸、滚到附近才画**，**滚出视野即释放画布位图**（只画不还等于把读过的每一页都钉在内存里）；按设备像素比绘制，高 DPI 下文字不糊；加密文档与损坏文档分开说明；上限 500 页 |
| 表格 | 首行固定表头，其余行滚动；解析按 RFC 4180（双引号包裹的字段里可以有分隔符、换行与双写引号）；上限 2000 行 × 100 列并如实标注 |
| Office | 如实说明转换服务未提供，并把「用系统里的应用打开」摆在同一屏 |

**`.xlsx` / `.xls` 归入「暂时无法预览」**：它们是压缩包，需要一套表格引擎才读得出来；本工作台没有内置引擎，因此不冒充 —— 空态里至少还能用系统里的应用打开。

### 12.6 引导页（默认页）

停靠栏的默认页，也是这一列的立足点：**独占停靠面时不画关闭入口**（关它等于关整列，这一手势归收起按钮）。新展开的面板只在仍然为空时播种它；从会话里点开一个文件得到的是那一个文件，不是「引导页加文件」两个 tab。默认页因此是会让位的：这一格只有它时，新打开的文件、终端或改动对比直接顶替它；整列只剩默认页时关掉最后一个内容 tab 也收起整列，下次展开默认页原样回来。

排版只有两件东西：一枚水印色的罗盘，和几个入口卡片。**不写标题** —— 这是一扇门，不是一页说明。

| 元素 | 值 |
|---|---|
| 容器 | 列向居中，间距 14px，左右内边距 24px |
| 抬升 | 末端一根 `flex: 0 1 10%` 的撑条，把整列抬到面板中线略上方（正中读起来偏下） |
| 罗盘 | 56px，水印色 `--color-watermark`，下外边距 16px；不是控件 |
| 入口卡片 | 宽 380px（窄栏里按 100% 收缩，保留 24px 侧边距），最小高 56px，内边距 14px 20px，间距 14px，圆角 20px，0.5px 发丝描边，底色 `--color-surface`，悬浮换底色 |
| 图形位 | 固定 26×26，因此每张卡片的文字都从同一条竖线开始 |
| 标题 | 14px，单行截断 |
| 说明 | 11px 三级文本色，标题之下 3px |
| 快捷键 | 右端 12px 三级文本色，按键名之间用一个 `+` 连接；**不画键帽** |

**入口由各 tab 类型自己声明**，引导页只按 `order` 摆：声明一个新入口不用回头改引导页。当前两个入口是「工作区文件」（`Ctrl + Alt + P`）与「新建终端」（`` Ctrl + ` ``）。

**点入口是让位，不是叠加**：入口把那个类型开在引导页的位置上（同一步替换，先关后开会让中间那一帧变成空格子）。

**「新建终端」多一个 shell 选择**：标题旁的箭头展开本机可用 shell 的菜单，查询只在展开时发生；整卡铺一张透明按钮负责「就用当前 shell 开一个」。终端入口的键位在工作区文件之下，因此视觉顺序与键位顺序一致。

**`+` 控件是回到引导页的路**：这一格已经有引导页时它没有意义，因此只在没有引导页时画出来。

### 12.7 用其他应用打开

工具栏最右侧的一枚**分裂按钮**加一张下拉菜单：

| 属性 | 紧凑态 | 强调态（不可预览的空态） |
|---|---|---|
| 高 | 24px | 36px |
| 圆角 | 8px | 12px |
| 描边 | 0.5px `--color-border-input` | 0.5px `--color-border` |
| 主按钮 | 内边距 3px 5px，图形 13px | 内边距 6px 14px，图形 18px，**带文字**（打开 / 显示文件位置） |
| 箭头 | 内边距 3px 4px 3px 3px，图形 10px，左侧 0.5px 分隔 | 图形 14px |
| 悬浮 | 两半都换 `--color-hover` | 同 |

**候选来自系统自己的关联登记，不是一份精选目录**：后端按文件扩展名向操作系统查询（Windows 走 Shell 的关联处理程序枚举，Linux 走 XDG 桌面条目，macOS 走 LaunchServices），因此换一台机器、装一个新应用，菜单会自己跟着变。菜单在**每次展开时重新查询**。

**跨平台关联程序查询**：各平台通过系统原生机制查询候选应用——Windows 通过 Shell 关联处理程序枚举并提取图标；Linux 通过 XDG 桌面条目及 mime 查询；macOS 通过 LaunchServices 与系统脚本查询候选。

**顺序原样沿用系统给出的顺序**：Windows 的关联枚举、macOS 的 `URLsForApplicationsToOpenURL`、Linux 的 `gio mime` 都自带优先级，平台中立的去重层只去重、不重排、也不把默认项搬到最前 —— 按名称重排会把「系统推荐谁」换成「字典序谁在前」。

**主按钮打开的就是菜单里标着「（默认）」的那一条**：系统给了默认标记就用它，否则用列表第一条（Shell 自己的偏好顺序）。两者永远指同一个应用，不存在「按钮说 A、菜单说 B」。系统没标默认时，主按钮把列表第一条**显式**报给后端，而不是让系统再解析一次关联。

**一个应用都没查到**（或查询失败，此时菜单里多一条禁用的说明行）时，主按钮退化为「显示文件位置」：文件定位始终可用，它不会因为关联查询出问题而消失。

菜单几何：

| 元素 | 值 |
|---|---|
| 卡片 | 内边距 4px，圆角 16px，`--elevation-prominent` 描边加柔光 |
| 宽度 | 144 至 360px，最大高 `calc(100vh − 24px)`，超出在菜单内部滚动 |
| 行 | 最小高 30px，内边距 4px 8px，间距 6px，圆角 12px，13px 正文；悬浮换底色 |
| 行图形 | 14px：应用图标（`data:image/png;base64` 数据地址），取不到或加载失败时退回通用「外部打开」图形 |
| 默认标记 | 主按钮将要打开的那一条，名称后缀「（默认）」 |
| 底部分隔 | 一行 `0.5px` 上边框（`--color-border`）加 3px 外边距，**不是菜单项** |
| 底部固定项 | 「显示文件位置」，文件夹图形 14px |
| 禁用行 | 40% 不透明度 |

**应用图标可能取不到**：图标是装饰，取不到不该影响候选本身能否被打开，因此每张图片各自带一次失败回退，而不是让整行消失。

### 12.8 终端

终端是停靠栏里**可以多开**的 tab 类型：一个终端一个 tab，关掉 tab 即关掉那个 shell 进程。

| 元素 | 值 |
|---|---|
| tab 图形 | 提示符图形；标题「终端」 |
| 正文 | xterm 屏幕，字号 13px，字体与应用其余等宽文本同一族，回滚 4000 行，光标闪烁 |
| 内边距 | 左右 8px，上 6px，下 4px |
| 退出态 | 一行状态说明（「终端已退出（代码 N）」或「终端已退出」）加一个「新建终端」胶囊：已退出的 shell 不自动重启 |
| 失败态 | 一行危险色说明，正文仍然挂着（便于看清是启动失败而不是空白） |

**尺寸双向同步**：容器变化时先按实际像素算出行列、把屏幕设成同一尺寸，再把尺寸转给 PTY，全屏程序据此重排。

**输出按原始字节写入**：终端输出不保证是合法 UTF-8，后端按 base64 送帧、界面解码成字节数组再交给 xterm，半截的多字节字符不会被拆坏。**输出通道先于终端建立**：会话标识要等建会话返回才知道，而 shell 的欢迎信息可能在那之前就到了，因此先到的帧按下暂存，拿到标识后再补写。

**浏览器调试模式没有终端输出通道**，因此那里给出明确说明而不是开一个看不见输出的终端。

### 12.10 本轮改动卡片

每一轮的收尾处集中展示这一轮改过的文件。事实源是订阅流上后端宣告的文件变更事件，
不做任何推断：没有变更事实就不画卡片；后端在同一轮内重复宣告的同一处改动按事实身份归并，
只算一份。

| 元素 | 值 |
|---|---|
| 卡片 | 圆角 12px，0.5px 发丝描边，底色 `--color-surface`，内边距与计划卡同一口径 |
| 头部 | 28px 行高，与计划卡、时间线过程行同一几何：12px 折叠箭头 + 14px 行首图形（多文件取代码图形，单文件取该文件的类型图形）+「改动」标签 + 13px / 20px 标题 |
| 标题 | 主文本色：多文件写「已编辑 N 个文件」，单文件写「已编辑 <文件名>」 |

| 折叠 | 默认收起，只留一行摘要；整行即折叠开关，箭头收起朝右、展开朝下 |
| 展开 | 按 `DisclosureBody` 缩进列出全部文件，不设「先四行再全部」的中间态，也不留重复的底部控件 |
| 悬浮反馈 | 头部不铺底色，只把箭头与行首图形提到主文本色（§5 的可展开行约定） |
| 文件行 | 高 28px，路径用界面字体主文本色，统计右对齐等宽；重命名在路径后接「 → 目标路径」；点行在右侧栏打开该文件的改动对比 |
| 落点 | 收尾分割线之前：改动属于这一轮真的做过的工作，分割线负责收口这一轮 |

**收起是常态**：卡片承载的是过程读数，一轮结束后先要读的是「改了多少」，明细按需求展开。
折叠态是本轮内的一次交互而非偏好，因此每张卡各自记自己的开合，新一轮的卡仍从收起开始。

**统计必须与对比页逐行对得上**：卡片上的增删行数、对比页工具栏上的增删行数与对比页真正
渲染出来的行数三者同源同口径。凡是「内容本身以 `--` 开头」的删除行，在 diff 文本里会呈现
成三连字符开头，它仍是内容行而不是文件头，不得被计数排除。

### 12.11 本轮改动对比页

右侧停靠栏里一轮改动一个 tab，标题写「第 N 轮改动」，资源地址是
`axon-resource://changes/<轮次序号>/<轮次标识>`，落的文件走导航参数，因此反复点开不同文件
只会切换落点，不会堆出一排标签。

| 元素 | 值 |
|---|---|
| tab 图形 | 代码图形：它承载的是一轮的代码差异，不对应单个文件 |
| 工具栏 | 与文件预览同高 38px、同一条 0.5px 下边框 |
| 文件选择器 | 多于一个文件时给出下拉：项内左路径右增删统计，当前项带选中标记 |
| 类型标签 | 新增 / 修改 / 删除 |
| 工具 | 自动换行、在侧栏打开整份文件、用其他应用打开（§12.7 的同一枚分裂按钮）、复制改动 |
| hunk 头 | 高 24px，底色 `--color-surface-sunken`，次级文本色，diff 原文照排 |
| 对比行 | 13px 等宽正文主文本色；新增底 `--color-diff-add`，删除底 `--color-diff-delete`，上下文不着色 |
| 行号 | 两侧各 4ch 右对齐等宽，次级文本色 |
| 符号列 | 2ch，新增 `+`、删除 `-`、上下文留空：颜色之外还有文本备份，色觉差异不影响可读性 |
| 同一文件多次改动 | 逐段渲染，每段之前一行「<类型> · 第 N 次」 |
| 截断 | 单份对比最多渲染 5000 行，超出即截断并在末尾如实标注 |

**对比只读**：正文取自后端随改动事件给出的 diff 原文，不回头向工作区另取一份内容，
因此文件此后又被改过也不会篡改这一轮已经发生的事实。工作区为空时这一页照常呈现，
只有「用外部应用打开」类动作因为拿不到根目录而不可用。

**交互约束**：左右分栏对比与悬浮改动浮层按需使用，不改变底层事实来源。

## 13. 后台任务与子代理列表

两个列表都挂在会话指标条的入口上，只在真的有对应事实时出现，详情收进下拉层。列表采用统一的作业面板规范：**同一套排版、同一套字号、同一套状态色**，因此两份列表具备高度一致的视觉语言。

### 13.1 列表容器

| 属性 | 后台任务 | 子代理 |
|---|---|---|
| 宽度 | 500px，最大 `min(560px, 100vw−32px)` | 336px，最大 `min(400px, 100vw−32px)` |
| 最大高度 | `min(480px, 100vh−140px)` | `min(560px, 100vh−140px)` |
| 内边距与间隙 | 3px，行间 1px | 同 |
| 滚动 | 列表内部滚动，滑块可见（`scroll-visible`）；**滚动列表不关闭菜单**，滚到面板外才关闭 | 同 |

### 13.2 任务行

进行中的行是一张**填充底色的卡**（左右内边距同时框住行与行尾控件），已结束的行压成**单行**：

| 位置 | 进行中 | 已结束 |
|---|---|---|
| 行首 | 状态点（14px 槽，与首行文字对齐） | 同 |
| 第一行 | 类型标签（命令）＋状态＋耗时 | 类型标签＋命令（弹性截断）＋结论＋耗时 |
| 行尾 | 方形展开箭头（20×20，常驻描边） | 同，仅在有输出时出现 |
| 卡外 | 停止键（20×20，首击武装成「确认停止」危险胶囊） | 无 |

行字 12px，类型标签与结论 10px，耗时 11px；命令用等宽字体并单行截断。

耗时文案按参考实现的两套口径分开：任务行**秒不补零**（`2分6秒`，小时档只说到分），子代理行**秒与分补零**（`2分06秒`，小时档说到秒）。同一列右对齐且等宽，因此数字变化不带着标题抖。

**在跑的行按秒走**：耗时由这一行第一次被看到的**服务端记录时间**起算，不是客户端第一次见到它的时间；列表打开且确实有在跑作业时每秒采样一次，静止的界面不起表。跑完的行改用后端实测耗时，因此终值不受采样时刻影响。

状态色与状态点表（§2.4）一致：运行中＝转圈，已完成＝绿，失败＝红，**正在停止与被停同为琥珀**（都属「按人的意思收口」）。

### 13.3 展开后的终端卡

卡片直接摊在行下方（左右各留 8px，底留 8px），一条命令横幅加一个输出区：

| 区域 | 规则 |
|---|---|
| 命令横幅 | 一行一个提示符 `$`；命令按原样换行铺满，**不可断行的长片段改为横向滚动**；横幅限高 148px，超出后内部滚动；多行命令在上限内滚动 |
| 退出码标签 | 只在跑完且非零退出、或没有退出码时出现（`退出码 3` / `未正常退出`），干净退出不画标签 |
| 复制 | 贴住横幅顶端常驻（命令滚走时仍在），回执为「已复制」，1.5 秒后回滚 |
| 输出区 | 等宽 11px，限高 288px 内部滚动，长行换行不横向溢出；没有输出时给「（无输出）」空态 |
| 运行中 | 尚无输出时只有横幅，不画空的输出区 |

### 13.4 子代理行

| 位置 | 内容 |
|---|---|
| 行首 | 状态点（14px 槽） |
| 第一行 | 子代理名称，单行截断 |
| 第二行 | 任务说明、状态，运行中再追加当前阶段，以 `·` 连接，10px 三级文本 |
| 第三行 | 模型名与缓存命中率（`命中 90.00%`），两者都缺时这一行不占位 |
| 指标列 | 第一行令牌数（`4.9M tok`），第二行耗时（`5分22秒`），右对齐、等宽 |
| 行尾 | 打开箭头（28×28 圆角按钮），点整行进它的运行轨迹 |

行高按内容自适应（标题 16px 起，每多一行加 16px），行内不做底色填充：状态由状态点与第二行的状态词承担，悬浮只换底色。参考实现的行里没有模型与命中率（它的会话摘要不带这两项），第三行是本工作台的补充。

## 14. 设置与关于

设置弹窗是「左侧二级导航 + 右侧正文」，关于页是其中一个分区。两个分区的职责**互不重叠**：关于讲产品是什么，系统设置讲它此刻跑成什么样。

### 14.1 关于页

按产品页面的通用形态组织，自上而下四段：

| 段 | 内容 | 规则 |
|---|---|---|
| 产品身份 | `AxonLogo` 44px + 产品名 + 首屏那句标语（15px，`brand.ts` 的 `BRAND_SLOGAN`）+ 一行 `版本 x.y.z · 许可` | 居中对齐；标语与首屏同一处定义，改一处即两处同步；版本与许可都取自构建期元数据，不写死字面量 |
| 发布渠道 | 项目主页 / 发布说明 / 问题反馈 | **按名字给入口**，用文字链接（13px、`--color-text-link`、悬浮转主文本色并加下划线）；不铺 URL、不用带箭头的胶囊按钮，完整地址只放在原生提示里 |
| 版本检测 | 一个主操作按钮加一行结论 | 主操作用实心主按钮；**排在发布渠道之后**，结论来自上面那一组坐标 |
| 失败详情 | 折叠的「详情」 | 归因与下一步动作收在这里，不糊在首屏 |

检测结论只有三种口径，首屏**只出现这三句之一**：

| 情形 | 首屏文案 |
|---|---|
| 已是最新 | 已是最新版本 |
| 有更新 | 发现新版本 vX.Y.Z（旁边补一个「前往下载」链接） |
| 失败 | 暂时无法检测新版本（下方给「详情」） |

- 首屏永远不出现 HTTP 状态码、库内部字符串、环境变量名或配置文件路径：这些是「详情」里的内容。
- 「详情」里的归因仍然要是中文的一句话，并附一条可执行的下一步；没有下一步就不放这一行。

#### 14.1.1 侧栏新版本入口

检测结论同时落到侧栏底部：**同一份检测事实，两个落点**。侧栏不另发一次请求，也不自己判断版本高低，出现与否由关于页那一次检测的结论决定。

| 属性 | 值 |
|---|---|
| 位置 | 侧栏底部设置行右端，与设置行同一 32px 行高、同一水平基线 |
| 几何 | 高 32px，左右内边距 12px，圆角 8px，0.5px 发丝描边，底 `--color-surface`（浮在托盘底色上的控件面） |
| 图形与文字 | 13px 下载图形加 13px 文案「新版本」，文字取 `--color-text-link`（`Button` 的 `link` 变体：与 `outline` 同几何同阴影，只换文字色） |
| 提示 | 原生 `title` 写「新版本：<tag>」，无障碍名称同文，因此读屏器读到的版本与肉眼一致 |
| 悬浮与按下 | 只换底色与描边强档，手感与 `outline` 按钮完全相同 |
| 出现条件 | 只在「检测完成、确认有新版本、且真有可打开的地址」时出现；无更新、检测失败、尚未检测一律整块不渲染，不留占位 |
| 点击 | 用系统浏览器打开该版本的首个安装包资产；没有资产时退回该版本的发布页；两者都没有就不出现（不留点了没反应的入口） |
| 打开失败 | 入口就地转为危险色、文案「下载失败」，原生提示写明原因与「点击重试」，再点即重试；不弹窗，也不在侧栏写红字 |
| 收起形态 | 侧栏收成 56px 图标轨时整块不渲染：图标轨每一格都是导航，混一枚状态入口会被读成又一个视图；关于页始终是它的常驻落点 |

侧栏这一格**不承担安装**：不做应用内静默安装、不做下载进度、不做「忽略此版本」。桌面端的发布事实仍然是安装树与 launcher，入口只负责把人带到发布资产。

### 14.2 系统设置

放两类东西：**改了立刻生效的开关**（消息通知，以及入口可见时的语音播报、语音输入设备），与**只读的运行状态**（Daemon、网关各面、远控连接、配置目录）。

- 语音输入设备是一个下拉加一枚试听按钮：候选来自系统真实枚举，选中哪一路就用哪一路，不回退；试听只读实时电平、不录音，离开设置页即释放设备。语音入口隐藏期间这一行与「语音播报」一起收起。

运行状态一律显示真实探测结论，探测失败如实显示未监听，绝不伪造成在线；版本号与发布渠道不在这里重复一遍。

### 14.3 分区级打开入口

右上角只有一个「打开」入口，目标随分区切换：配置类分区开 `config.toml`，MCP 开 `.mcp.json`，技能开技能目录，人设与准则开各自的源文件。

**只有配置真正落地的分区才有这个入口**：系统设置与关于没有对应的配置文件，这两个分区不渲染任何按钮，也不退回去开 `config.toml` 凑一个位置。目标文件不存在时同样不渲染。

### 14.3.1 设置 › 人设

人设分区是「只读状态面板 + 音色（本地偏好，语音入口可见时才有） + 源文件编辑器」三段，顺序不可颠倒：先让人看见这个人格此刻是什么样，再让他选朗读音色，最后改源文件。音色不写入 `SOUL.md`，只存本地偏好（`axon.voice.preset`，空值表示跟随人格）。语音入口隐藏期间这一段收起，其余两段顺序不变。

| 段 | 内容 | 数据来源 |
|---|---|---|
| 人格状态面板 | 内核解析结论、持久化状态、最近转移、已发布习得风格、状态库体积 | 网关 `/api/v1/persona/summary`，只读 |
| 音色 | 一个下拉加一枚试听按钮，默认跟随人格；停用预设仍在下拉里列出并标注「当前不可用」 | `voice_presets` 命令 + 本地偏好 |
| 源文件编辑器 | `SOUL.md` 原文 | 本地文件读写 |

- 音色是**单选**，因此用下拉而不是平铺五行：同一时刻只有一副嗓子生效，把候选项摊成一张表会把「我选了哪个」藏进一排等宽行里。触发器只显示当前音色，展开后才给候选；停用项保留在列表中以说明「为什么不能选」。
- 试听按钮紧贴下拉右侧，试听的是**当前选中**这一副嗓子；试听中图标换成声波加停止，与消息朗读按钮同一套发声语言。
- 自动朗读开关关闭时用静音喇叭图形（带叉），开启时用有声波喇叭，发声时换成声波：三种形态一一对应「关、开、正在响」，不靠文字解释。

- 状态面板复用 `Panel` 与 `ListRow`，不新增卡片形态、不新增色值：它是既有基元的组合，不是第二套视觉。
- 内核无效时用 `Banner` 给出一条可执行的失败原因；状态库尚未建立时用 `EmptyHint` 说明「完成一轮私聊对话后写入」，不留空壳，也不伪造基线。
- 面板内的读数一律等宽右对齐，时间收成「月-日 时:分」，与全站时间口径一致。
### 14.4 外壳层不得成为滚动容器

页级外壳（根节点、主区域、内容包装）一律用 `overflow-clip`，不用 `overflow-hidden`：`hidden` 仍然是一个**可滚动容器**，键盘把焦点移进面板内部控件时，浏览器会为「把焦点滚进视野」而悄悄滚动它（实测 23px，整条指标条被推到侧栏底下）。`clip` 让它彻底不是滚动容器。

真正需要滚动的只有正文、列表与侧栏自己那几层，它们用 `overflow-y-auto` 且滚动是刻意设计的一部分。这条与 §12 的浮层裁剪同源，也是弹窗面板用 `overflow-clip` 的同一个理由。

## 15. 用量看板（数据可视化）

用量统计分区（设置 › 用量统计）是工作台里唯一成规模的数据可视化界面。本节是它的视觉与口径规范，与前面的通用规则叠加适用；冲突时以本节为准。

### 15.1 图表色板

数据图形需要多条序列同时可辨，因此**独立于界面语义色**另立一支图表色板（`tokens.css` 的 `--color-chart-*`）：

| 令牌 | 值 | 用途 |
|---|---|---|
| `--color-chart-input` | `#3b6fe0` | 未缓存输入 Token |
| `--color-chart-cache-read` | `#9dbdf0` | 缓存命中读取 |
| `--color-chart-cache-write` | `#2f9d8f` | 缓存写入 |
| `--color-chart-output` | `#7d6bd6` | 生成输出 Token |
| `--color-chart-reasoning` | `#b4762a` | 推理输出 Token |
| `--color-chart-requests` | `#6b7280` | 请求数（另一套量纲，取中性灰） |
| `--color-chart-plot` | `#f7f8fa` | 绘图区底板 |
| `--color-chart-grid` | `rgba(15,17,21,0.06)` | 网格线 |
| `--color-chart-track` | `rgba(15,17,21,0.06)` | 条形与进度条的底槽 |

三条铁律：

1. **图表色只进图形，不承载文字**。所有读数、标签与图例文字一律走 `--color-text-*`，因此不受正文 AA 约束；每一条图例逐项带名称（或读数），信息不依赖颜色本身。
2. **语义色不参与序列配色**。`--color-ok`、`--color-gold`、`--color-danger` 只表示成功、告警与失败（健康时间线的终态），不做「第几条序列」。
3. **同一量纲才同图**。Token 构成、请求数、成本三种度量用**一张图切换指标**实现，不做双轴叠加与任何形式的隐藏归一化：两条量纲不同的线画在同一个绘图区里，读者无从判断各自是什么量级。实时吞吐因此改成**上下两条条带**（Token 在上、请求数在下），共用一条时间轴与同一个悬浮读数，各自带自己的刻度。

### 15.2 版面与几何

| 元素 | 值 |
|---|---|
| 分区正文宽度 | 用量统计与模型定价沿用设置页的 960px 面板（其余分区 720px 表单列，见 `ui-constraints.md` §4.2） |
| 面板 | `bg-surface`、发丝描边、`rounded-md`、内边距 14px，与 §11 条目卡片同一档外观 |
| 面板间距 | 12px；两列并排时同样 12px（`xl` 以下退化为单列） |
| 绘图区 | 底 `--color-chart-plot`、圆角 8px、发丝描边；主图高 180px，实时吞吐的 Token 条带 116px、请求条带 52px |
| 网格线 | 1px `--color-chart-grid`，等分 3 至 4 档，画在图形之下 |
| 刻度文字 | 10px 等宽三级文本色，y 轴在左、x 轴在绘图区下方 4px |
| 读数气泡 | `bg-surface` + Level 2 阴影 + 发丝描边，内边距 6px 8px，贴边时改为左/右对齐而不是居中裁切 |

**几何一律用百分比坐标**（SVG 不设 `viewBox`，面积与折线用 `polygon` 与 `polyline`）：容器多宽图就多宽，不需要测量 DOM，描边与圆点也不会被非等比缩放拉扁。图形内部**不放 `<text>`**：文字全部由 HTML 排版，因此字号、行高与全站同一套令牌。

### 15.3 时间轴口径

- **时间轴由周期决定，不由数据条数决定**。网关只返回有数据的桶，界面按选定粒度补齐整段时间轴（缺的桶补零）：空档就是空档，看得见；直接把数组按顺序平铺会把三个小时的用量摊满一周。
- 粒度：今天按小时、7 天按六小时、30 天与更长按天（超过 180 个桶自动再降一档到周）。
- 时间桶按本地日历对齐（小时、天、周都落在用户时区的自然边界上），只有六小时桶用本地整点取整。
- 健康时间线最多回看 14 天（行是天、列是小时），再多就退化成一片糊掉的色块。

### 15.4 口径与空态

- **缺观测就说缺观测**：没有样本的分位写「无观测」，不补零；成本未定价写「未定价」，不画一条全零曲线冒充统计结果。
- **概览与明细必须同源**：健康时间线的成败口径与大盘汇总一致（终态 `completed` 计成功，其余终态计失败）；日历的活跃档位由网关按窗口内最大值分级，界面不重算。
- **进不了图的事实要写出来**：零值样本不参与散点，就在脚注里给出被跳过的条数；榜单单页只列 10 项，就把其余项的合计写在脚注里。
- **每分钟就是每分钟**：实时吞吐按自然分钟给出实测值（10 秒槽位合并成分钟桶），不把短窗口的计数乘系数冒充更长时间的量；窗口总量与构成明细、概览、分布三处同口径（输入、输出与推理之和）。
- **读数用「最近有数据的那一分钟」**：请求是零散的，写严格的本分钟读数会让速率一栏在两次请求之间一直显示 0，读起来像坏了；因此速率栏取最近有数据的一分钟并把时刻写出来，读数不会被误当成此刻。
- 每个面板都有自己的空态文案（说明缺什么、为什么缺），不留空壳、不留占位假数据。
- 图表绘图区的空态用 `EmptyPlot`（占住绘图高度的描边底板加一行说明）：它是一个共用件而不是随手写的空态，且必须占住高度，否则空态与有数据态之间卡片高度会跳。

### 15.5 交互与动效

- 悬浮读数用**整列命中**（趋势图）或**点自身命中圈**（散点）：指针不必压在细柱或小圆点上。
- 条形入场只做 `transform: scaleX` 的生长（`.bar-grow`，320ms `--ease-standard`）：动画宽度会触发布局，十几行逐行重排是看得见的抖动。减弱动效下由全局规则直接落到终态。
- 读数在刷新期间**保持不变**，只把「正在刷新」写在控制条上：整个看板每次轮询闪成骨架，比晚一帧更难读。

### 15.6 分屏与模块边界

用量看板与模型定价都按「**页签分屏 + 每屏若干独立面板**」组织：

| 元素 | 规范 |
|---|---|
| 页签条 | 吸顶（`sticky top-0`），高 28px，13px 正文，选中项用 2px 下划线指示器而不是填充块：页签是导航，与「周期 / 维度 / 窗口」这类分段控件必须在视觉上分开 |
| 页面底板 | `--color-surface-sunken`，`min-h-full`：面板取白底才能从底板上浮起来 |
| 面板 | 白底 + 发丝描边 + `rounded-md` + `shadow-panel`，三层结构：标题层、图形层、读数层 |
| 层间边界 | 标题层与读数层各有一条发丝线与图形层分开；读数层底色下沉一档（`--color-surface-sunken`），图例、合计与口径说明都停在那里 |
| 跨页签控件 | 周期与刷新停在页签条右侧；维度、指标、窗口这些只影响单块的筛选放在各自面板的标题行里 |
| 分页条 | 面板读数层的一部分：左侧「第 N 至 M 条，共 X 条」，右侧每页条数与页码；页码序列由 `paginationMath` 给出，全站共用一份实现 |
