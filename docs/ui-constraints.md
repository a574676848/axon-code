# Axon Desktop UI 约束规范

> **定位**：这是 `crates/axon-desktop/ui/**` 所有 UI 任务的**开工前置契约**与**验收清单**。
> 视觉取值与交互细节的单一事实源仍是 `docs/workbench-design-system.md`；本文件负责把其中不可协商的部分提炼成可执行约束，并规定 UI 任务的开工与收口流程。
>
> **强制要求**：任何 UI 相关任务（新建页面、改布局、调样式、加组件、修交互）在动第一行代码之前，必须先完整阅读本文件与 `docs/workbench-design-system.md`。未读不得修改界面代码。

---

## 1. 适用范围与优先级

- 适用于 `crates/axon-desktop/ui` 下的全部页面、组件、令牌与样式。
- 约束优先级：长官当前指令 > 本文件 > `docs/workbench-design-system.md` > `frontend-ui-ux` Skill > 既有组件习惯。
- 发现冲突时，**先改本文件或设计系统，再改实现**，不允许代码与文档各说一套。
- 不新增第二套视觉语言、第二套图标体系、第二套组件库或自带样式的第三方组件库。

## 2. 令牌与颜色

- 颜色、字号、圆角、阴影只能来自 `src/tokens.css` 的 `@theme` 与 `:root` 令牌。组件里禁止出现颜色字面量。
- 唯一豁免：`components/conversation/fileIcons.tsx` 中第三方语言与工具标识的美术还原，色值属于资产本身。
- 三套主题：纸白（默认，不挂属性，`paper`，清透亮白）、冷杉（`data-theme="forest"`）与黑曜石（`data-theme="obsidian"`，暗色模式）。三套共用几何、字号与组件形态，只换调色板、光影与语法色板，取值见 `docs/workbench-design-system.md` §0.1、§0.2、§0.7。
- 表面四级：托盘底座（侧栏）、主画布（内嵌圆角舞台）、浮起卡片、下沉凹槽。纸白为 `#F6F6F7`（侧栏） / `#FAFAFC`（通透洁白画布，压暗半度以便与纯白卡片形成明度差） / `#FFFFFF`（卡片） / `#F3F3F5`（下沉面）；冷杉为 `#E7EEEA` / `#F2F5F4` / `#FAFCFB` / `#E1EAE5`；黑曜石为 `#0B0D11` / `#11141B` / `#181C25` / `#0D1016`。卡片靠底色差、同源描边与顶部微高光同时浮起。
- 半透托盘底座 `--color-sidebar-translucent` 只在系统材质可用时生效：纸白与冷杉取各自托盘底色的 0.70（Windows 11 Mica）/ 0.78（macOS Vibrancy），黑曜石取 0.60 / 0.75。窗口失焦、最大化或材质不可用时一律退回 100% 实色 `--color-sidebar`。
- 窗口四角由托盘底座自己裁：`border-radius: 10px` 只管 `.app-shell-tray`，且只在系统材质生效（窗口真能透光）时开启；最大化时归零。不走 DWM 的 `DWMWA_WINDOW_CORNER_PREFERENCE`，因为那需要 `unsafe` 调用，而工作区禁止 `unsafe_code`。
- 文本档位（纸白 / 冷杉 / 黑曜石），全部满足正文 AA 4.5:1：
  - 主文本（标题、加粗词、主标签） `#111113` / `#111C18` / `#ECEFF4`
  - 叙述正文（`--color-text-prose`，长文阅读醇正墨色） `#242428` / `#203029` / `#D4D7DE`
  - 次文本 `#52525B` / `#3B4B44` / `#A6B0C0`
  - 三级文本 `#63636B` / `#52635B` / `#8B95A7`
  - 占位 `#6E6E77` / `#5C6D65` / `#838E9E`
  - 说明与时间戳 `#65656D` / `#54655D` / `#8892A4`
  - 链接与技能 `#1D5BD6` / `#18634A` / `#79A6FF`
  - 行内代码墨色（`--color-code-ink`，配无框柔底胶囊） `#27272A` / `#174B38` / `#93C5FD`
- 语义色：
  - 危险文字 `#B91C1C` / `#B3261E` / `#F87171`，危险浅底由各自取值派生。
  - 成功标记 `#22C55E`，成功文字 `#0F6A31` / `#156839` / `#4ADE80`。
  - 琥珀标记 `#F59E0B` / `#E39B22` / `#F59E0B`，琥珀文字 `#8A5200` / `#855505` / `#FBBF24`。
  - 标记与文字分档，标记色不得直接承载文字。
- 主操作色 `#18181B` / `#144534` / `#2F5FD0`（白字对比度全部 >= 4.5:1）；主按钮悬浮态 `#27272A` / `#1B5742` / `#3B6FE2`。
- 聚焦环 `#2563EB` / `#217658` / `#528BFF`，键盘可见，鼠标点击不显示。键盘焦点微环另立 `--color-focus-ring`（`rgba(24,24,27,0.25)` / `rgba(20,69,52,0.35)` / `rgba(76,130,247,0.45)`）：1px 实线加 2px 扩散微光，用于列表行与命令面板这类高频键盘流转动线。
- 列表悬浮 `--color-row-hover`（`rgba(24,24,27,0.04)` / `rgba(17,28,24,0.05)` / `rgba(255,255,255,0.045)`）与文本划选 `::selection`（`rgba(24,24,27,0.12)` / `rgba(20,69,52,0.15)` / `rgba(47,95,208,0.32)`）各自成角色，覆盖浏览器默认的刺眼亮蓝与系统默认悬浮。
- 主题漫反射阴影 `--shadow-surface-drop` 参与色相联动：纸白与冷杉带各自墨色相（`rgba(24,24,27,...)` / `rgba(14,30,24,...)`），黑曜石取纯黑。
- 消隐细滚动条：轨道透明，滑块取 `--color-scrollbar-thumb`（纸白 `rgba(24,24,27,0.14)` / 冷杉 `rgba(17,28,24,0.16)` / 黑曜石 `rgba(255,255,255,0.16)`），悬浮加深至 `--color-scrollbar-thumb-hover`（`0.18` / `0.20` / `0.22`）。宽度恒定 8px、`background-clip: content-box` 加 2px 透明内缩边，因此肉眼看到的是 4px 细条；占位恒定，滚动区不因内容变长而横向跳动。
- 每套主题各自只有一个强调色与一个主操作色。禁止在主题之外再引入强调色、AI 紫、霓虹泛光与装饰性渐变。
- 主题只允许改颜色、描边、投影、高光棱、语法高亮与图表色板；几何、字号、间距、组件形态与动效曲线必须在三套主题之间完全一致。
- 画布与卡片必须存在可辨明度差：纯白卡片压在以 `--color-canvas` 铺开的舞台上，低色域显示器上也不能被吞成一片。
- 模态遮罩只用 `--color-scrim` 加 2px 背景模糊，嵌套弹窗不得叠第二层遮罩；遮罩只允许动 `opacity`，模糊半径保持常量。

## 3. 排版

### 3.1 角色阶梯

| 角色 | 字号 / 行高 | 用途 |
|---|---|---|
| 展示 | 26 / 32 | 首屏品牌标语 |
| 一级标题 | 21 / 30 | 页面标题、正文 h1 |
| 二级标题 | 18 / 26 | 分区标题、正文 h2、统计大数 |
| 三级标题 | 15 / 24 | 正文 h3、小区块标题 |
| 正文 | 14.5 / 26 | 助手回答长文（配 `--color-text-prose` 柔和对比度） |
| 界面行 | 14 / 20 | 列表主行、配置标签、导航、页签 |
| 控件与表体 | 13 / 20 | 输入、下拉、按钮、表格 |
| 说明 | 12 / 20 | 说明段、卡片描述 |
| 紧凑说明 | 12 / 16 | 单行元信息、表头 |
| 代码 | 12 / 20 | 代码块、预览、行号 |
| 角标 | 11 / 16 | 快捷键角标 `Kbd`、分组小标题，字间距 `0.02em` |
| 微标签 | 10 / 16 | 仅时间戳、计数、坐标轴刻度 |

### 3.2 硬性规则

- 14px 是界面主行，13px 是控件与表格，两者不得在同一行交替。
- 10px 不得承载中文说明、字段标签、表头或按钮文字。快捷键角标与分组小标题取 11px（`text-micro`），不占用 10px 档。
- 字体族只有两支，且都取系统栈：界面 `--font-sans`（`-apple-system` 打头），代码 `--font-mono`（显式带 `'Microsoft YaHei'` 兜底，不以裸 `monospace` 收尾）。不打包 webfont，不得新增 `@font-face`。
- 组件里禁止用裸 `text-base`、`text-lg`、`text-xl`、`text-2xl` 做标题；一律使用令牌档。
- 标题层级：h1 21、h2 18、h3 15 取 700 字重；h4 14 取 600；正文 `strong` 600，不得与标题同重。
- 每行字数：对话正文 45 至 75 个汉字；设置表单列不超过 720px；侧栏正文约 26 字；代码不设限，横向滚动。
- 数字一律 `tabular-nums`；单位与数字之间保持同一口径；日期收成「同年 10/21 17:14」与「跨年 2026年10月21日 17:14」两档，界面不显示秒。
- 中英混排取 `text-autospace: normal`，由引擎在相邻的 CJK 与拉丁之间补间距；代码与等宽片段取 `no-autospace`，保留源文本的列对齐。
- 中文与拉丁之间留半角空格；中文不使用等宽字体；全站禁止 en dash 与 em dash。

## 4. 几何与控件

### 4.1 尺寸与圆角

| 角色 | 值 |
|---|---|
| 控件高度 | 32px |
| 小动作 / 图标按钮 | 28px |
| 顶栏高度 | 40px（侧栏品牌行、对话页指标条、管理页顶栏、右侧停靠栏 tab 条统一对齐） |
| 控件圆角 | 8px |
| 主舞台内嵌画布圆角 | 12px（嵌于托盘底座内，上下右留 6px 托盘边） |
| 卡片 / 面板 / 代码块圆角 | 12px ~ 14px |
| 弹窗圆角 | 16px |
| 输入坞圆角 | 外层托槽 22px + 内层核心 18px（双层同心倒角） |
| 胶囊 | 只用于开关、分段控件、标签、发送键 |

- 输入、下拉、数字、文本域必须是同一高度、同一圆角、同一 13px 字号、同一蓝色聚焦态。
- 按钮默认 8px 圆角；不再使用胶囊命令按钮。图标按钮的命中区不小于 24px，优先 28px。
- 间距只取 4、6、8、10、12、16、20、24 的节奏；同一区块不得出现 6 与 7 混用。

### 4.2 页面骨架

- 沉浸式一体窗口：Windows 与 Linux 关闭系统默认标题栏（`decorations: false`），由右上角 `WindowControls` 承载最小化、最大化/还原与关闭；macOS 采用 `TitleBarStyle::Overlay` 保留原生左上交通灯。所有 40px 顶栏自带 `data-tauri-drag-region` 拖拽热区，最右列自动避让窗口控制区。
- 对话页：40px 指标条 + 定宽对话流（最大 840px，可拖拽）+ 底部双层倒角输入坞。首屏与会话必须共用同一个宽度变量，切换不得横向跳动。
- 指标条不重复模型：模型由输入坞右下角选择器常驻承载；上下文段只给已用/窗口，缓存命中率作为独立读数直接显示，有完整输入 token 时才出现。工作态也不写品牌名：只在最左给一枚强调底色的活动点（22px，`aria-label="正在运行"`），运行结束即消失。
- LSP、MCP 与计划属于辅助读数，放在指标流末尾；窗口不足时先收起辅助簇，再收起性能簇。MCP 段只在有服务器或读不到结论时出现，有服务器加载异常时整段取危险色并给出台数。
- 管理页（工作区、自动化、目标看板、记忆）：`PageShell`，40px 顶栏（左标题 14/20，右动作 28px）+ `max-w-page`（88%）+ 唯一滚动层。
- 目标看板页：顶栏之下依次是描述一行、工具栏（搜索 + 状态分段 + 计数）与四栏看板。栏目用容器查询栅格，默认一列，560px 两列、820px 三列、1080px 四列；栏目底板取下沉面、卡片取浮起面，因此只有两层，不出现卡片套卡片；页面只有一层滚动，栏目自己不滚。进入只读执行会话时自带 36px 顶栏，与看板态互斥，不叠出第二条标题栏。
- 设置：单一面板尺寸（960px 宽，高度随视口并设上限），左侧 184px 分区导航，右侧表单列最大 720px；分区标题 16/24 + 一句 12/16 说明；底部状态行固定。
- 侧栏：展开 280px，图标轨 56px；栅格固定为 12px 外边距 + 24px 图标列 + 8px 文字列；窗口小于 1024px 自动收轨；用户手动偏好优先。
- 右侧停靠栏：默认收起，展开 45%；tab 条 40px；末格控件 28px；分栏阈值按真实控件宽度计算，不足时禁用并说明原因。
- 模态：140ms 淡入 + 轻微上移，只动 opacity 与 transform；退出走 110ms 缩放退场（见 §6）；嵌套弹窗不再画第二层遮罩；下拉必须 portal 到 body 并做窗口夹取。
- 命令面板（`Ctrl + K` / `Cmd + K`）：居中调出的浮层，命中跨视图跳转、工作区与会话、设置分区与已安装技能；键盘独占（上下移动、Enter 执行、Esc 收起），列表行悬浮与键盘共用同一档 `--color-row-hover` 高亮。

### 4.3 滚动与层级

- 外壳层用 `overflow-clip`，不做滚动容器；真正滚动的只有正文、列表、侧栏与面板自身。
- 长内容滚动区挂 `scroll-visible`，让用户看得见还有内容。
- z 轴只保留三档：正文浮层、菜单、模态。禁止随手写 9999。

## 5. 状态、组件与复用

- 状态标识只用 `StateDot`：在跑为转圈，完成为绿点，失败为红点，暂停或中断为琥珀，静息为灰点。
- 状态文案只显示中文，不直接输出后端的 `active`、`completed`、`removed` 等枚举。
- 列表行状态只有三档：静止、悬浮 `bg-hover`、选中 `bg-active`；选中可以加 2px 主色指示，但必须与悬浮明显区分。
- 过程行与可展开行（思考、执行、工具、改动、计划）的悬浮态不铺底色：只把行首图标从三级文本色提到主文本色，光标保持 pointer，焦点仍用键盘焦点环。整行反色会让阅读中的正文闪一下，这一段不采用。
- 空态、加载态、错误态只允许 `EmptyState`、`LoadingState`、`Banner` 三种形态；不得手写 `py-12` 空态或行内红字。
- 同类条目集合统一用 `EntityCard` / `CardList`：一个类型标签、一处定位信息、右下角唯一的「查看配置」入口。
- 条目卡另有三个可选插槽，默认值不改变任何既有视觉：`leading`（行首节点，目标看板放状态点）、`locatorMono`（定位行是否等宽，默认 `true`，目标看板传 `false` 放中文文案）、`actionIcon`（页脚动作图标，默认齿轮）。新增卡片集合不得为此重写一套卡片视觉。
- 模型选择的用途必须分开：对话模型选择（主模型、快速模型、输入坞模型选择器）只列非 embedding 模型；向量模型选择只列 embedding 模型。两者共用 `isEmbeddingModel`，`supports_embedding` 为准，名称含 `embedding` 作为供应商漏标时的兜底。
- 模型编辑必须读写 `supports_embedding` 与 `embedding_dimension`：关闭 Embedding 时维度归零，打开时给出有效默认维度并允许修改；加载模型时不得把这两个字段丢掉，否则保存会写出不合法配置。
- 以下形态全站只有一份实现，出现第二份即视为缺陷：
  - 可展开行（`DisclosureRow`）
  - 菜单与候选列表（`MenuPanel` / `MenuRow`）
  - 下拉选择（`Select`，含停用项与说明列；音色这类单选一律走它，不平铺成行）
  - 分页（`ui/pagination`）
  - 分段控件（`SegmentedControl`）
  - 表单字段（`FormField`）
  - 状态点（`StateDot`）
  - 页级外壳（`PageShell`）
  - 条目卡外壳（`ComposerTile`，附件卡与链接卡共用）
  - 网址占位（输入框底衬占位符、链接卡与消息气泡里的链接芯片）
  - 声学声波微动画（`VoiceWave`，输入坞麦克风、语音状态行、消息朗读按钮、顶栏自动朗读开关与音色试听行共用）
  - 快捷键角标（`Kbd`，菜单项、按钮提示与命令面板共用 11px 角标）
  - 命令面板（`CommandPalette`，`Ctrl + K` 的唯一入口）
  - 弹出层退出生命周期（`useExitLifecycle`，模态与输入坞上沿面板共用）
  - 输入坞上沿状态条外壳（`ComposerStatusCell`，语音录音条与工作状态行共用；只定义高度、圆角、底色、阴影与内部节奏，左端标识与文案由各自给）
  - 麦克风原生授权与隐私修复引导（`ComposerVoicePermissionDialog`，基于 `Dialog` 承载首次授权说明、系统隐私跳转与重新检测，宿主层静默接管本地源的 WebView 媒体权限，严禁露出浏览器 URL 权限条）
- 同一内容在不同页面出现 80% 以上相似结构时，先抽共用组件，再写页面。
- 禁止卡片套卡片套卡片；禁止用 div 拼假截图；禁止假数据、假按钮与不可用控件伪装成可用。

## 6. 动效与无障碍

- 只允许对 `transform` 与 `opacity` 做动画；禁止动画 `top`、`left`、`width`、`height`、`margin`、`padding`。
- 禁止对 `display: inline` 的元素声明 `transform` 动画：行内盒子的变换会按行盒逐段重算，流式正文每来一批 token 就重排一次。流式正文的入场因此只在块级单元上做（`.stream-block-in` 的 4px 上浮），行内文字不动。
- 物理弹簧三档曲线（三套主题完全一致）：触觉 `--ease-spring-tactile: cubic-bezier(0.34, 1.56, 0.64, 1)`、稳健滑行 `--ease-spring-smooth: cubic-bezier(0.16, 1, 0.3, 1)`、柔和退场 `--ease-spring-exit: cubic-bezier(0.4, 0, 1, 1)`。
- 按键遵循非对称时间法则：松开回位 200ms 弹簧，按下 50ms 极速下沉（`translateY(1px) scale(0.985)`）；通用按钮上不得常驻 `will-change: transform`。
- 弹出层有入场与退场两条时长：入场 180ms，退场 110ms（`data-state="closed"` 的缩放淡出，走完才卸载）。遮罩只动 `opacity`，模糊半径恒为 2px，严禁动画化 `backdrop-filter`。
- 主题切换走双 `requestAnimationFrame` 瞬切锁：切换那一帧给根节点挂 `.disable-transitions`，第二帧之后摘掉，因此不会出现颜色逐个插值的残影。
- 声学声波（`VoiceWave`）以 Canvas 绘制：按 `devicePixelRatio` 放大位图再 `ctx.scale` 归一化逻辑坐标，振幅走非响应式环形缓冲区；静息收敛后立即 `cancelAnimationFrame` 停表，待机 CPU 占用为 0。
- 声学声波（`VoiceWave`）与朗读进度细线只允许驱动 `transform: scaleY(...)`、`transform: scaleX(...)` 与 `opacity`：麦克风采集与音频播放优先按实测振幅包络（`0..1`）驱动柱体缩放，静默间隙回落至低幅呼吸；`prefers-reduced-motion` 下冻结为静态错落刻度，保留活跃语义但零位移。
- 禁止 `window.addEventListener('scroll')`。滚动位置相关逻辑用 `IntersectionObserver`、滚动容器自有回调或 ResizeObserver。
- 必须实现 `prefers-reduced-motion` 降级：位移、缩放、旋转、循环扫光全部落到终态。
- 常用时长：100ms 悬浮、110ms 弹出层退场、140ms 模态入场、150ms 开关与回执、250ms 抽屉。
- 所有可交互元素必须有 `:focus-visible` 反馈；图标按钮必须有 `aria-label`；列表与菜单要有正确的 role 与键盘行为。
- 图标统一线性、`currentColor`、12/14/16/20/24 五档；禁止用 emoji 代替图标；同一语义只用一个图形。

## 10. 变更协议

1. 先改规范：新增颜色、字号、圆角、状态或组件形态时，先更新本文件与 `docs/workbench-design-system.md`。
2. 再改令牌：在 `src/tokens.css` 里成角色，不在组件里写字面量。

4. 最后改页面并复拍：每个页面至少覆盖默认态、空态与一个失败或加载态。
5. 文档门禁：新增文档必须在 `docs/README.md` 建索引；本文件变更需同步 `AGENTS.md` 的强制阅读声明。

## 11. 现行已知例外

- `fileIcons.tsx` 的第三方语言与工具标识保留品牌色，不适用「组件零字面量」。
- 10px 仅限时间戳、计数与坐标轴刻度；不得扩大用途。
- 少数格式化函数（如延迟单位、规则时间）被既有测试逐值锁定；界面展示若需新口径，另建共享格式化函数，不直接改被测试锁定的旧函数。
- 桌面窗口最小宽度为 800px；小于 1024px 自动收为 56px 图标轨，因此不实现更窄窗口的覆盖式抽屉。
- 品牌标识的内部小字是资产的一部分，不按正文文本的可读性标准考核。
- `EmptyPlot`（`components/usage/charts/chartKit.tsx`）是图表绘图区专用的空态：它是共用件而不是手写空态，且必须占住绘图高度，否则同一张卡片在空态与有数据态之间会跳高度。
