# 系统概览

Axon 是为个人与工程创造者打造的**专属个人智能体（Personal Agent）与战术协同平台**，核心理念是「**知你所想，办你所托**」。它融入你的工作区与工作节奏：在桌面工作台、终端界面与命令行之间共享同一套会话历史、记忆与技能，在每一次交互中持续深化对你的理解。

本页只讲产品能力与边界。想了解具体操作，直接跳到本文末尾的文档入口。

---

## 1. 三种使用形态

同一套运行时支撑三种界面，能力一致，入口不同：

| 形态 | 适合谁 | 典型场景 |
| --- | --- | --- |
| 桌面工作台（Axon Desktop） | 需要长期开着、边看边改 | 多会话并行、任务面板、用量与诊断看板、模型与密钥设置 |
| 终端界面（TUI） | 习惯在终端里连续作业 | 全屏对话、快捷键切会话、快速查看状态栏读数 |
| 命令行（CLI） | 脚本、自动化、一次性任务 | 单次运行、无头调用、把 Axon 接进已有流水线 |

三端不是三个产品：桌面端发起的一轮对话，在终端里打开同一条会话能看到；反之亦然。会话归属由你显式指定（桌面左侧会话列表、TUI 的 `/sessions`、CLI 的 `--session`），运行时不会替你猜。

## 2. 一次请求会发生什么

从你按下回车到看到结果，用户能感知到的行为只有五步：

1. **提交即入账**：输入先被可靠记录下来，客户端断网或窗口关掉，任务也不会丢。
2. **有序排队**：请求按工作区与渠道排队，同一个队列内串行执行，不同队列互不阻塞。
3. **流式交付**：模型输出、工具调用与执行进度边跑边推，桌面端与终端实时看到增量，不需要刷新。
4. **工具落地**：读写文件、执行命令、检索文本、加载技能、调用 MCP 服务等动作以卡片或列表形式呈现，参数与结果都可见。
5. **可回放**：每一轮的终态、来源渠道与产物都留在会话里，重新打开可以接着看、接着聊。

需要跨回合推进、需要等待外部结果、或者需要后台托管的工作，会被登记为**后台工作**：即使你关掉界面，它也会继续推进，回来时从上次的位置继续读。

## 3. 能力边界

**能做**

- 多轮对话与长会话续聊，历史按会话隔离，跨端一致。
- 在你的工作区里读文件、改文件、执行命令、跑后台作业，权限按风险分级拦截。
- 分层记忆：稳定偏好长期保留，临时事实按需召回，记忆可查、可改、可删、可重建。
- 技能扩展：用 Markdown 写工作流，按需装载，不占用常驻上下文。
- MCP 协议接入：stdio 与流式 HTTP 两种形态，支持 OAuth 授权与凭据安全存储。
- 语音输入与朗读（云端识别与合成），桌面端与终端共用同一套语音能力。
- 定时任务、多模型供应商路由与故障切换、用量看板与请求审计。

**不预设**

- 不内置模型价格表：费用字段在没有价格规则时统一显示为「未定价」，需要你维护价格规则才会给出成本。
- 不猜测未完成的状态：没有终态证据的请求保持「进行中」，系统不会替你判定成功或失败。
- 不替你做跨会话的身份推断：会话由你显式选择，历史不会在会话之间互相串。

**数据在哪**

- 会话、记忆、技能、配置、用量等运行数据全部保存在本机运行根目录下，卸载应用不会自动删除。
- 桌面端不直接读写这些数据，一律经本机网关接口访问；网关只监听本机地址并需要凭据。
- 只有在你发起推理时，对话内容才会发送给你所选的模型供应商。
