# 终端 TUI 交互

运行 `axon`（不带子命令）即进入全屏终端工作台。它与桌面工作台、命令行共享同一套会话、工具与记忆，不是另一个产品。

---

## 1. 界面布局

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部状态栏：模型 · 思考 · 耗时/累计/命中率 · 上下文 · 首字/速率 │
├──────────────────────────────────────────────────────────────┤
│ 会话视口（独立滚动）                                          │
│   · 你发的消息                                                │
│   · 助手流式回复（Markdown、语法高亮、Diff）                  │
│   · 工具调用状态行（可折叠）                                  │
│   · 交互式提问面板位置                                        │
│   · 每轮用量分割线                                            │
├──────────────────────────────────────────────────────────────┤
│ 输入坞：多行编辑（/ 命令、$ 技能、@ 文件）与快捷键提示         │
└──────────────────────────────────────────────────────────────┘
```

顶部状态栏读三组信息：

- **模型与思考强度**：都只作用于本会话，不写回配置文件，退出重开回到默认值。恢复旧会话时显示的是那一轮真正使用的模型与它的上下文窗口。
- **耗时、累计用量、缓存命中率**：三段连读回答「这条会话一共花了多少」。耗时是各轮实际耗时之和，累计是输入、缓存读写、输出与推理的总和，命中率是缓存读取占完整输入的会话累计比例，不是单轮值。读数为零的段不显示，不会渲染成 `0`。
- **上下文与实时速率**：上下文段显示最近一次请求的构成（含缓存与写入），首字与速率是整条会话的平均，收口后的每轮分割线给出该轮自己的数值。
- **读数一旦出现就常驻**：顶栏这六段都是会话级事实，产生之后不会因为某一轮结束、某一轮失败或视图滚动而消失；只有换到另一条会话（`/sessions` 选中别的会话、`/new`）才随会话身份一起归零。`/clear` 只清正文，顶栏读数原样保留。

进入工作台时会话视口先落一段首屏，收尾行是 `入口已就绪 · MCP 3 · Skill 32`。两个读数都是入口盘点，不是工具条数：MCP 是已连上的服务器台数，Skill 是已载入的技能条数；有服务器没起来时补一段 `失败 1`。具体是哪台、为什么失败、各自带了哪些工具，看 `/mcp`。

## 2. 输入与快捷键

| 操作 | 行为 |
| --- | --- |
| `Enter` | 提交输入 |
| `Alt+Enter` / `Shift+Enter` | 换行 |
| `↑` / `↓` | 在视觉行之间移动；到边界后浏览历史输入 |
| `Ctrl+R` | 搜索历史输入，取消时恢复未提交的草稿 |
| `Ctrl+X` | 用 `VISUAL` / `EDITOR` 指定的编辑器打开当前内容 |
| `Esc` | 有待处理队列时先处理队列，否则中断当前任务 |
| `/` `$` `@` | 打开命令、技能、文件上下文候选 |

运行中继续输入不会丢：内容进入队列，在安全边界注入当前任务。

内容来自本地会话与运行事件，界面只渲染结构化单元，不会绕过工具审批边界。

## 3. 斜杠命令

| 命令 | 作用 | 运行中可用 |
| --- | --- | --- |
| `/help` | 查看 TUI 能力与常用命令 | 是 |
| `/clear` | 清空当前会话视图，保留顶部状态栏 | 否 |
| `/sessions [--all]` | 打开会话弹窗，选中后载入该会话历史；`--all` 含归档会话 | 否 |
| `/new` | 开启新会话，下一轮使用新的会话标识 | 否 |
| `/reset` | 重置当前会话的运行实例，保留会话标识与历史 | 否 |
| `/model <model>` | 切换下一轮使用的模型（只作用于本会话） | 否 |
| `/think` | 设置推理强度（只作用于本会话） | 否 |
| `/status` | 查看当前 TUI 运行状态 | 是 |
| `/mcp [list\|login\|logout <server>]` | 查看 MCP 服务器与工具清单，或完成 OAuth 授权 | 是 |
| `/skills [list\|toggle]` | 查看或开关技能 | 是 |
| `/exit` | 退出（别名 `/quit`、`:q`、`exit`、`quit`） | 是 |

`/new` 与 `/reset` 的区别是会话标识：`/new` 换一条会话，下一轮落在新会话里；`/reset` 只换这条会话的运行实例，会话标识与历史都保留。需要换话题用 `/new`，需要让同一会话换一个干净的执行实例用 `/reset`。

`/model` 与 `/think` 只影响本会话的后续轮次，不改配置文件。

### 候选弹窗

命令、模型、思考强度与会话四个弹窗是同一套交互：左列给出可直接执行的条目，右列只补左列没有的事实。上下键移动选中项，选中整条在内容区高亮并跟着走；`Enter` 执行或载入，`Esc` 关闭。弹窗始终按真实可用高度开窗，选中项不会滚出可视区。

左列与右列按弹窗分工，都不复述对方已经写着的东西：

- 命令：左列是命令本身（`/model`），后面跟参数提示（`<model>`）；右列说明这条命令做什么。
- 模型：左列只写模型名（命令名已经打过了），右列写 provider 与上下文窗口。
- 思考强度：左列只写强度名，右列留空；强度名本身就说清了动作，不再逐条重复同一句说明。
- 会话：每条一行，标题在前、来源（provider 与模型）贴住行尾，归档会话在这行前面标 `已归档`。

会话列表按**当前工作区**收敛，与桌面端一致：在哪个目录启动就只列那个工作区的会话，`/sessions` 选中的会话按同一份运行态事件还原正文、工具回执与该轮读数。这个工作区还没有会话时，弹窗直接说明，而不是把别的工作区的会话摆进来。

---

MCP 服务器需要 OAuth 时，首屏加载完成后只提示一次并给出 `/mcp login <server>`；Axon 不会自动打开浏览器。登录在后台执行，不阻塞界面。

## 4. 用户提问面板

模型把决定交给你时，输入区上方弹出提问面板；面板打开期间按键全部归面板。

- `↑` / `↓` 在选项间移动并环绕；焦点在自定义答案里时先退出自定义，再回到选项列表，已输入内容保留。
- `空格` 勾选或取消，单选题替换，多选题可多选。
- 直接输入字符进入自定义答案，`Backspace` 回退。
- `Enter` 提交当前题，还有下一题就前移，最后一题交出全部作答。
- `Tab` 显式跳过当前题，这是空选择，不是取消提问。
- `Esc` 收起面板但不取消：窗口延长或重新进入会话时面板会再出现；在自定义答案里 `Esc` 只退出编辑。

## 5. 过程中能看到什么

- **工具调用**：每次调用一行，折叠态只给一句话说明这次调用要达成什么，展开后看参数与完整输出。
- **文件变更**：写入类工具直接把文件差异作为该次写入的展示，不重复贴一份同源回执。
- **计划**：任务拆解成计划后，同一张计划卡片原地更新状态（待办、进行中、完成），不会重复追加新卡片。
- **思考过程**：流式阶段展开可看，这一轮结束后自动折叠，标题保留耗时，需要时仍可展开。
- **子代理**：完成时追加一行终态记录，详情按耗时、Token 消耗、摘要排列；结果过长时完整内容会落到运行根的归档目录，通知里给出可读取的路径。
- **用量分割线**：每一轮结束时在正文下方补一条该轮自己的读数：用时、Token 与分桶、命中率、首字与速率，和顶部的会话累计口径分开。「有没有跑工具」不是条件，纯对话回合同样有这一行；已经写下的分割线不会因为后面的轮次被改写或抹掉。

## 6. 恢复与异常表现

- 重新打开 TUI 时，优先接上仍在进行中的那一轮；没有进行中的轮次就显示最近一次已完成回合的回复与用量分割线。
- 运行中连接断开会自动按进度重建一次；长时间没有任何事件时会显示一次空闲提示，但不会取消你已提交的任务。
- 等待中出现「本轮已结束，无需中断」这类提示，说明这一轮在后台已经收口，正文会按顺序补齐。
- 后台服务不可达时给出结构化失败提示，已产生的内容不会丢；先用 `axon daemon status` 确认服务状态。
