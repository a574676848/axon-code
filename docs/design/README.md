# 界面设计规范

本目录存放 Axon 桌面工作台的界面设计与开发契约，面向维护者和贡献者，不属于产品说明。产品可见行为见 [桌面工作台](../desktop.md)。

| 文档 | 内容 |
| --- | --- |
| [UI 约束规范](./ui-constraints.md) | UI 任务的开工前置契约：令牌、颜色、排版、几何、组件复用、验收门禁与设计终检清单。任何界面改动动工前必读。 |
| [工作台设计系统](./workbench-design-system.md) | 视觉与交互的事实源：调色板、字号、圆角、组件形态、动效曲线与状态呈现。 |

两份文档的关系：设计系统定义「取值是什么」，UI 约束提炼「不可协商的部分」并规定开工与收口流程。新增颜色、字号、圆角、状态或组件形态时，先改设计系统，再改 UI 约束，最后改实现。

相关入口：[贡献指南](../../CONTRIBUTING.md)、[产品文档索引](../README.md)。
